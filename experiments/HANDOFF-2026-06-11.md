## 二、What worked（值得延续）

1. **双审查循环每个任务都抓到真 bug**：模型注入 `_dataDir` 任意路径写入、`writeFile mode` 不收紧已存在文件权限（红绿实测）、中文输入法 Enter 误发、busy 期间丢输入、纯中文选题知识库静默失配（CJK bigram 修复）、tokenizer 中英混写盲区、排序测试假阳性（靠 sort 稳定性误过）、PendingEdit 选区定位竞态……**不要跳过审查**。
2. **实现者对审查/计划的红灯反证**：多次出现「审查者给的修复代码本身不够/计划伪码有错（allowedTransitions 包络、*** 单行前瞻）」，实现者用 TDD 红灯证明后修正——「给定代码逐字使用，红灯证明的缺陷允许最小修正并报告」这条提示词纪律是关键。
3. **引擎考古先于新建**：S2.7 启动前 grep 发现 local-store 早有 versions/回滚/11 态流转、content-save 早有 update/transition——省掉一半工作量。**动手前先翻 src/storage 与 src/tools**。
4. **CDP 冒烟脚本模式**：隔离 HOME + `--use-mock-keychain` + 独占端口 + 截图断言，每个 sprint 末跑真机全链路（含 XSS 注入实测）。
5. **创始人资产挖掘**：qingmoagent（github.com/alextangson/qingmoagent，已克隆过 /tmp）的 SelectionToolbar/PendingEdit 交互 90% 直接搬；其 **PRD-style-calibration.md（576 行三阶段风格校准）是未来「LLM 风格建模」的现成设计稿**。

## 三、What failed and why（教训已固化）

1. **cwd 漂移踩了三次**（commit 进错分支、冒烟测了 main 的旧构建、worktree 里把分支 merge 进自己）。已写入持久记忆 `autocrew-worktree-smoke-discipline.md`：worktree 操作一律绝对路径/显式 cd；**合并收尾固定序列 = 主检出 cd → merge → 验证 → worktree remove → branch -d**。
2. **HOME 覆盖触发 macOS 钥匙串弹窗**骚扰创始人（找不到 Electron Key），且一个冒烟实例忘杀挂在他屏幕上。根治：冒烟一律 `--use-mock-keychain` + 用完 pkill（runbook 排查表有条目）。
3. **chrome-devtools MCP 的 Chrome 长期占用 9333 端口**——electron bind 失败后盲跑，CDP 连到了别人的浏览器。换端口（9555/9666/9777/9888 已用过）并先验证 page.url。
4. **gstack 设计技能（design-consultation/shotgun）会话中途不可用**——改为手工出三方向 visualize 小样给创始人挑，效果更好（落了 DESIGN.md）。
5. **36kr RSS 偶发失败**（爱范儿稳定）——failedSources 机制兜住，源清单在 `src/data/topic-sources.json` 可扩。
