# 个人 IP 视频字幕包装

适用于本用户的个人 IP 口播与剪映交付。用户于 2026-09-25 明确：字幕一般使用剪映新青年体，不用描边，使用阴影包装。这是已明确的默认偏好，无需再次索取样式确认；项目明确指定其他品牌规范时遵循该项目，不把此偏好推广到所有客户视频。

## 默认样式与可编辑交付

- 口播字幕默认使用剪映实际可用的 **新青年体**。核对字体名称、资源 ID 或实际字体文件；其他渲染器的 `Xinqingnian Ti` 只是待核对映射，加载成功不等于与剪映完全一致。字体缺失时报告具体缺口，不静默替换。
- 使用实心字面，默认白色；**关闭描边，描边宽度为 0**。检查字幕模板、预设、逐字样式与继承样式，不能仅新增阴影而保留原有黑边。不要用多方向硬阴影或叠字伪装成描边。
- 使用柔和深色投影分离字与背景：轻微向下偏移、适量模糊和透明度。优先沿用已认可的原生阴影参数；没有样例时按画面调节，不虚构剪映控件单位，也不把某组像素值当成所有分辨率的固定标准。
- ChatCut Desktop 里已实测的对应参数、单行与语义重断句做法见 [chatcut-local-editing.md](chatcut-local-editing.md)。
- SRT 只交付文字与时间，不能携带这套字体包装。剪映中保留独立可编辑字幕；ChatCut 先剪、剪映包装时，沿用项目现有字幕分工，避免两套字幕叠加。不要把口播字幕烧进 B-roll。
- 修改已交付草稿时，先检查当前样式，在同一个已确认草稿内更新；备份放在草稿列表之外。仅改字体包装不改口播、字幕文案、切分、时间或原音轨。更新 skill 本身不代表旧草稿已被修改。

## 画面适配

- 连续口播字幕保持稳定，不逐字跳动、不每句换动画。短词、人名和产品名完整保留，按自然语义换行。
- 关键词花字与口播字幕分层，沿用新青年体与柔和阴影；少量主题色、下划线或手写圈线服务于强调，不能让两层文字争抢注意力。
- 浅色网页、白色产品界面和复杂 B-roll 先检查阴影、字号与摆位。需要改善时适度调整阴影或把字幕放到安全留白，不默认恢复描边或添加厚重底条。
- 避开人物面部、重要按钮、结果与数据；按最终画幅保护字幕安全区，检查手机缩小观看的可读性。

## 包装验收

读取实际样式，并检查带字幕的原生合成画面：真人口播、最浅/最复杂的 B-roll、中文英文混排和切换边界。确认字面实心、无硬轮廓、阴影不糊字，且没有双字幕或遮挡关键结果。记录实际字体、描边关闭状态、阴影参数及截图/时间点。

样式参数写入、SRT 校验或素材解码都不等于视觉验收。只有预览验证时就写预览已验证；已获导出授权时再检查实际导出中的字体与阴影，不为了样式检查擅自启动整片导出。此检查纳入既有成片审核，不增加审核节点。
