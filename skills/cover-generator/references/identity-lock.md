# 个人 IP 身份锁定与多比例延展

## 跨视频选形象，同一期锁身份

身份一致不等于每条视频复用同一造型。先根据本期的工作场景、情绪和表达动作，从可用形象库选取合适人物，并检查可查的近期封面是否重复姿态、衣服和角度。先前明确选中的生活照只在它所属的封面方案中锁定；除非用户明确要求跨期统一，不得升级为永久人物模板。用户已授权作为人物母图的生成生活照可以直接合成，但必须先做本期适配选择；其他未批准候选保留待审状态。

将本期选图的路径、选择理由、与上一版的变化和实际审批状态记入项目。选定本期母图后，再执行下面的身份保护与同母本横竖延展；不能用跨期造型多样性为由在同一对封面里换脸。

## 参考图优先级

先核对当前工具支持的参考图数量与引用方式；前三张优先顺序如下，不把某个 API 的三图上限套用到 Codex 内置工具：

1. 当前真实身份照：锁脸型、五官比例、发际线和日常眼镜。
2. 真实编辑肖像：补骨相、轮廓、上镜气质，不改变身份。
3. 真实表情照：补眼神、嘴角和姿态。

AI 生成肖像默认不进入前三位。用户明确选中它的角度或姿态时，可替换第 2 或第 3 位，但只能提供姿态；提示词必须再次声明第 1 张真实照片是唯一身份真值。

## 四种处理模式

### 新封面

从真实参考照生成 A/B/C 三个内容驱动方案。先看标题是否构成第一点击理由，再看人物是否像本人；不要用工位、代码墙、连帽衫制造程序员刻板印象。

### 局部修脸

当构图已对、脸部脏或略不像时，以当前图片为编辑目标，只改脸与颈部安全区，要求标题、身体、手、服装和场景不变。人物皮肤允许自然毛孔，但不得带背景的纸纹、裂纹、油墨颗粒、浮雕感或强制雀斑痘印。

默认 Codex 内置 Image 2.5 路线：本地图先用 `view_image` 查看，再按实际编辑合同引用。没有 mask 参数时不虚构遮罩或像素锁定保证；明确局部修改意图，实际比较输出，漂移则不通过。用户明确要求字节级保护而工具无法保证时，只报告该能力缺口，不自动转付费 API。已授权 API 若支持 mask，才按其真实合同构建保护区；不静默降级为从头整张生成。

### 标题与排版修订

人物已通过时，只用所选路线的局部编辑处理文字/背景区，要求保留人物并实际验证。中文和核心英文必须逐字正确；核心选题名、产品名或数字是最大文字，情绪钩子居次。任何文字都不得穿过脸和眼镜。禁止改用 HTML、SVG 或其他确定性排版覆盖成品。

### 多比例延展

内置路线将选定 `3:4` 母版作为编辑目标，为 `4:3` 单独规划版式：按横向阅读顺序安排标题、人物、主题图示和留白，文字位置、换行和场景布局可以变化，但文案含义和同一人物素材不变。人物只能保持自然比例地移动和缩放，不能横向拉伸、另画脸、改表情；不能把竖版缩小居中后单纯补左右背景当成合格横版。不要用原 prompt 独立重生整张横版。若工具不能保证像素保护，必须如实说明并实际对比，不能靠提示词或哈希声称人脸已锁定。

默认独立流程使用用户已批准母本；四节点 paired_draft 允许尚未批准但已内部选定的母本，两张一起待审，不写入假批准。记录两图哈希和衍生关系，哈希不能代替实际身份对比。

如果新比例里人物偏小，可向内置编辑工具要求适度近裁且保留身份。顶部标题和底部信息条都必须完整，不以放大人物为由重新生成脸。

## 创作者身份与上镜边界

- 默认保留细矩形眼镜、长脸轮廓、眉眼和鼻唇比例；发型可整理成自然、有层次的美式前刺，但不改变发际线。
- 默认气质是有判断力、时尚、克制的创作者/导演。表情要么冷静审视、轻微不对称自信，要么明确夸张并服务选题；不要停在呆滞中性表情。
- 允许均匀肤色、清理临时痘印和脏纹、增强眼神光、优化轮廓光；不允许瘦脸、放大眼睛、重塑鼻子、改变眼距或女性化处理。
- 最终封面人物要比普通生活照更上镜，但第一眼仍必须被本人和熟人认出。

## 验收视图

至少检查三个视图：

1. 原尺寸整图：看图层、文字、肢体和场景连接。
2. 100% 人脸裁切：看身份、眼镜、皮肤脏纹、AI 蜡感和五官异常。
3. 200px 宽缩略图：看核心标题是否可读、人物是否足够近、点击理由是否清楚。

独立模式在 3:4 批准后生成 4:3；paired_draft 先出同母本配对草稿，再合并审核。只有明确选择 AutoCrew API 路线时才依赖其 draft_ratios。两种比例并排检查；脸、眼镜、发型和表情任一明显变化都算身份漂移，不能通过。
