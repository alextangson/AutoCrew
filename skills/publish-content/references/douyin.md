# 抖音操作

入口：https://creator.douyin.com/creator-micro/content/upload

| 步骤 | 动作 | 成功条件 / 已知故障 |
|---|---|---|
| 账号与上传 | 核对昵称和稳定 ID；通过视频上传控件选文件 | 正确文件名与上传完成，不能只看 setInputFiles 成功 |
| 标题 | 填写作品标题输入框 | value 与发布包一致 |
| 描述 | 用当前富文本编辑器，全选、清空，再插入完整描述 | 本次 `fill` 曾追加内容；必须读回全文，不能只看截断 snapshot |
| 话题 | 每次输入一个 #词，等原生候选，选准确项 | 编辑器出现对应 contenteditable=false 节点；五个话题分别确认 |
| 双封面 | 分别设置横版4:3、竖版3:4 | 每张上传后检查标题完整，再保存；回到表单确认两个槽位 |
| 声明 | 按发布包选择自主声明，并确认弹窗 | 表单显示所选声明 |
| 发布设置 | 核对可见性、是否同时发其他平台、立即或定时 | 不额外开启同步发布；读回选中状态 |
| 提交 | 保存提交记录后点击一次发布 | 等管理页出现本条，而非仅页面跳转 |
| 回执 | 本条卡片状态与时间；必要时点标题进入详情 | 详情 URL 的 work-detail 后是作品 ID；“作品状态正常”与管理页已发布作为后台证据 |

不要把“检测人数过多，作品检测失败”写成内容审核被拒。保留具体提示。
公开播放页若未核实，记录 verification_scope=creator_management，不假称已验证公开播放。

## 适用与失效

以下方法在 2026-10-15 的发布中观察到。先核对当前页面结构与控件；不是永久选择器保证。
只使用当前 snapshot/DOM 已观察到的目标。旧 ref、坐标、随机 class 后缀不复用。
成功条件未满足时不进入下一步。最终提交规则见主 Skill 与发布契约。
