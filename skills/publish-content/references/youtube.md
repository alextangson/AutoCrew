# YouTube 操作（英文版）

> **未经实测**：这份手册在第一次真实发布前写成，页面结构没在 ego lite 里走过。第一次发布由创始人在场，逐步核对后把观察到的控件和故障补进表里，再去掉这行。

入口：https://studio.youtube.com （右上「创建 → 上传视频」）

发的是英文版那条稿（`en_edition` 派生稿，平台 `youtube`）：成片 = 英文版登记的成片，缩略图 = `edition:{op:"set_thumbnail"}` 登记的那张 16:9，文案 = `youtube` 发布包（标题、描述含章节行和标签、tags）。默认时段：**北京时间 21:00–23:00（美国上午）**，不跟中文时段。

| 步骤 | 动作 | 成功条件 / 已知故障 |
|---|---|---|
| 账号 | 核对右上头像对应的频道名和频道 ID（Studio 网址里 `/channel/UC…`） | 与发布计划的账号一致。**没登录或登到别的账号：停下请创始人登录**，不跳过这个平台、不换账号 |
| 上传 | 「创建 → 上传视频」，用文件选择控件选登记的英文成片 | 看到上传进度和「处理中 / 检查完毕」，不能只看 setInputFiles 成功；文件名与登记文件一致 |
| 详细信息 | 标题、说明：清空后粘发布包原文 | 读回全文：标题 ≤100 字符；说明里章节行（`0:00 …` 起）完整、标签在末尾 |
| 缩略图 | 「上传缩略图」选登记的 16:9 图 | 预览出现这张图；账号没验证电话时这个按钮不可用——停下告诉创始人，不跳过 |
| 观众 | 「不是为儿童打造的」，按发布包 | 读回选中状态 |
| 更多选项 | 「标签」逐个粘 tags；语言选 English | 标签都在框里 |
| 视频元素 / 检查 | 结束画面、卡片不加；等版权检查结果 | 有版权提示就停下报原文 |
| 公开范围 | 选「安排时间」，日期时间设到计划的时段（时区按页面显示核对，换算成北京时间读回） | 读回日期、时间和时区；**不选「公开」立即发** |
| 提交 | 保存发布记录后点一次「安排」 | 弹出「视频已安排发布」和视频链接 |
| 回执 | 记视频链接（`youtu.be/<id>`）、安排时间、状态「已安排」 | 内容页里本条显示为「已安排」 |

章节在说明里生效的条件：第一个是 0:00、至少 3 个、每段 ≥10 秒——发布包交包时已核过，读回时只看有没有被截掉。

## 适用与失效

只使用当前 snapshot/DOM 已观察到的目标。旧 ref、坐标、随机 class 后缀不复用。
成功条件未满足时不进入下一步。最终提交规则、回执和防重发见主 Skill 与发布契约（点之前先查本平台有没有已提交的回执）。
