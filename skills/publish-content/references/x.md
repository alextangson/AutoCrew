# X 操作（英文版）

> **未经实测**：这份手册在第一次真实发布前写成，页面结构没在 ego lite 里走过。第一次发布由创始人在场，逐步核对后把观察到的控件和故障补进表里，再去掉这行。

入口：https://x.com/compose/post

发的是英文版那条稿（`en_edition` 派生稿，平台 `x`）：视频 = 英文版登记的成片，文案 = `x` 发布包的帖子正文（≤280 字符，标签已并进去）。默认时段：**北京时间 21:00–23:00（美国上午）**。

| 步骤 | 动作 | 成功条件 / 已知故障 |
|---|---|---|
| 账号 | 核对左下角头像的 @用户名 | 与发布计划一致；长视频要 Premium 账号。**没登录：停下请创始人登录**，不跳过 |
| 写帖 | 正文框清空后粘发布包原文 | 读回全文一致；右下字数圈没变红 |
| 视频 | 「媒体」按钮选登记的英文成片 | 等上传进度走完、出现视频预览；超出账号的时长 / 大小上限会直接报错——**原样记下报错，停下告诉创始人**，不压缩、不换文件 |
| 定时 | 「安排」（日历图标）设到计划的日期时间 | 读回日期、时间和时区，换算成北京时间核对；按钮变成「安排」而不是「发帖」 |
| 提交 | 保存发布记录后点一次「安排」 | 提示已安排；「未发送的帖子 → 已安排」里有这条 |
| 回执 | 记已安排列表里这条的时间与正文开头；公开后补帖子链接（`x.com/<用户名>/status/<id>`） | 状态「已安排」 |

已安排的帖子要改要撤，在「未发送的帖子 → 已安排」里操作；英文成片换版后，旧的已安排帖子必须先撤掉再按新版重排，不能假设它会自己取消。

## 适用与失效

只使用当前 snapshot/DOM 已观察到的目标。旧 ref、坐标、随机 class 后缀不复用。
成功条件未满足时不进入下一步。最终提交规则、回执和防重发见主 Skill 与发布契约（点之前先查本平台有没有已提交 / 已安排的回执）。
