# 视频号操作

入口：https://channels.weixin.qq.com/platform/post/create

| 步骤 | 动作 | 成功条件 / 已知故障 |
|---|---|---|
| 账号与上传 | 核对账号；找到 accept 为 video 的文件控件 | 出现上传进度，结束后显示视频与封面槽 |
| 微前端 | 本次控件位于 `wujie-app` 的 open shadowRoot | 语义点击被宿主遮挡后，使用已观察 DOM 的 click 或当前截图坐标，不重试同一失效点击 |
| 文案 | 填短标题和 `.input-editor` 描述 | 读回 shadowRoot 内实际 value/innerText |
| 话题 | 定位编辑器末尾，每个词单独输入，再发 Space | 每个词形成 `.hl.topic` 节点后再加下一个；末尾词可能延迟转换 |
| 竖封面 | 点击个人主页卡片编辑；若出现“使用此素材”提示，先选直接编辑 | 确认弹窗标题为编辑个人主页卡片，再上传3:4并查看裁切 |
| 保存竖封面 | 点弹窗确认，等待弹窗消失且该槽更新 | 保存尚未结束时不能点横版，否则可能串槽 |
| 横封面 | 打开编辑分享卡片，上传4:3 | 确认裁切，再等待保存结束；检查两个槽位最终预览 |
| 其他设置 | 核对位置、活动、不定时/定时、视频标注 | 没有授权的位置不要沿用自动定位；根据素材选含AI生成内容等实际声明 |
| 提交 | 保存提交记录，点一次发表 | 回到列表并出现本条描述及发布时间 |
| 分享链接 | 定位本条 `.post-feed-item`，点分享图标 | 文本“分享”本次不是触发控件；图标打开复制视频链接菜单 |

复制链接后先确认“已拷贝至剪贴板”。使用 ego 已支持的剪贴板读取方式；若浏览器权限提示需用户处理，按 ego 规则交接。
替代方法：在本页已知、空白、不会自动发起搜索的输入框粘贴刚复制内容，读取并清空，不按 Enter；只保留符合微信分享域名的结果，不输出其他剪贴板内容。
真实分享短链可为 `https://weixin.qq.com/sph/...`，只能手机微信打开。保存来源为本条分享菜单。
AutoCrew 若不识别短链，保留 `sync_status=pending_verification`；不要伪造长链或代创始人确认。
