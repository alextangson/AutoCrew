# 小红书操作

入口：https://creator.xiaohongshu.com/publish/publish

| 步骤 | 动作 | 成功条件 / 已知故障 |
|---|---|---|
| 账号与上传 | 核对账号，上传本轮成片 | 正确文件名、上传完成，高清视频提示可辅助确认 |
| 封面 | 上传批准封面，按 check 要求明确选择3:4 | 编辑器可能默认4:3；查看实际裁切，再保存 |
| 描述 | 填完整标题与描述 | 读回全文；光标先 focus 再用 DOM Range 定位末尾 |
| 话题 | 单个输入，等待准确候选再选 | `.tiptap-topic`/data-topic 原生节点；必须验证标签集合 |
| 活动 | 所有话题完成后检查活动组件 | 添加独立开发等词可能自动关联无关活动，取消错误关联；不要宣称取消活动等于取消话题 |
| 声明设置 | 添加内容类型声明，核对公开可见与定时开关 | 按发布包选择，不能自行承诺内容合作 |
| 提交 | 保存记录，点击一次发布 | 等“发布成功”，再到笔记管理补齐标题、时间、状态 |
| 公开与ID | 点击本条封面打开详情页 | 核对账号、标题、视频和活动话题链接；URL explore 后为笔记 ID |

活动有的只要求主/子话题，有的要求专门组件，按本次官方规则执行。
不为追求活动组件而反复删除重加已正确的话题。简单模型不自行判定活动资格。
审核中不填要求公开笔记的返稿表。公開后按活动与跟进文档去重、回填。

## 适用与失效

以下方法在 2026-10-15 的发布中观察到。先核对当前页面结构与控件；不是永久选择器保证。
只使用当前 snapshot/DOM 已观察到的目标。旧 ref、坐标、随机 class 后缀不复用。
成功条件未满足时不进入下一步。最终提交规则见主 Skill 与发布契约。
