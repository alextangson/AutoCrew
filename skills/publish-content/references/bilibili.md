# B站操作

入口：https://member.bilibili.com/platform/upload/video/frame

| 步骤 | 动作 | 成功条件 / 已知故障 |
|---|---|---|
| 账号 | 用已登录自己的主页验证 UID | 昵称与稳定 ID 匹配 |
| 上传 | 检查当前文件 input，使用真实视频上传控件 | 本次 `name=buploader` 设置成功但未上传；隐藏的 accept=.mp4… 文件 input 才触发。必须看到上传进度/完成 |
| 文案 | 填稿件标题与简介富文本 | 读回 title 与简介全文，避免把动态编辑器当简介 |
| 声明分区 | 按内容选择创作声明与分区 | 不保留根据文件名自动猜测的错误设置 |
| 标签 | 删除自动生成的无关标签；逐个输入并 Enter | 等 `.label-item-v2-content` 出现本项后再填下一项；立即连续填会漏词 |
| 封面 | 上传4:3批准图，核对两个预览 | 16:9个人空间封面可能仍是原视频帧；按需启用双比例同步，再检查标题不被裁切 |
| 发布设置 | 核对定时、商业推广、活动 | 不误选推荐活动；不把“立即加热”当完成步骤 |
| 提交 | 保存记录后点一次立即投稿 | 等“稿件投递成功”，再点查看进度 |
| 回执 | 管理页本条标题链接给出 BV 号 | 保存时间与状态；公开页核对标题、作者 UID、视频 |

标签是 Enter 后异步生成，动作成功不能证明标签已经创建。

## 适用与失效

以下方法在 2026-10-15 的发布中观察到。先核对当前页面结构与控件；不是永久选择器保证。
只使用当前 snapshot/DOM 已观察到的目标。旧 ref、坐标、随机 class 后缀不复用。
成功条件未满足时不进入下一步。最终提交规则见主 Skill 与发布契约。
