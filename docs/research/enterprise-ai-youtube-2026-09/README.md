## 跨组主线

六组卡合起来指向三句话，外加一个真实分歧。口播立意从这里选，别从概念选。

1. **稀缺的不是模型，是只在某个人手上、从没写下来的那一步判断。** Box 的 90→99 要坐到处理员旁边；退款 agent 的公司卡规则；Palantir 的双击；江总的「全是纸」；刘胜男的员工藏着不说。你的 FDE 访谈录音入库流程就是在干这件事，这是别人拿不到的一手。
2. **采用率不等于价值，瓶颈不会消失只会搬家。** AK 和 BCG 双源印证「用得越热闹越可能白花钱」；Goodfolio 的合规瓶颈搬家；BCG 的「42% 每周省出一天，66% 没人告诉他这一天干什么」。你自己的 57 篇 0 发出是最诚实的例子。
3. **失败率数字是一条传播链的产物，你是链上唯一在现场看过失败长什么样的人。** 95% 来自 52 场访谈的方向性估计，被 Fortune 引爆、被 98 万播放固化、被厂商借去卖产品、退化成正片不引数字的标题党。A 组文末有整张溯源表。

**真实分歧**：Kevin 说「不改员工动作，只在原流程里抽掉一半时间」，BCG 和顾问报告说「只做工具部署的企业被全方位碾压，必须端到端重构」。解释是单价：5 万台币的单重构不了流程，三五十万的才行。把这条讲清楚比站边有价值。

## 原始材料与复现

字幕文本、Whisper 转写、元数据都在 `~/.cache/autocrew-yt/`（tx/ 字幕与音频，turbo/ 本地转写，cards/ 素材卡副本）。不放 /tmp，机器重启过一次全丢了。

重新拉一条字幕：

```bash
yt-dlp --no-update --write-sub --write-auto-sub --sub-lang en --skip-download -o "~/.cache/autocrew-yt/tx/%(id)s" "https://www.youtube.com/watch?v=VIDEO_ID"
```

中文视频语言列表里把 zh 放在 en 前面会让英文视频整条失败，分开请求。无字幕视频拉音频要加 `--extractor-args "youtube:player_client=mweb"`，默认客户端 403。本地转写模型在 `~/.cache/autocrew-yt/mlx-turbo/`（whisper-large-v3-turbo，M2 Pro 上 30 分钟音频约 1.5 分钟）。
