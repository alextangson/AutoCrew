## 1. 他怎么对待原文（V1 对照 Collison 原推）

### 1.1 骨架照原文的顺序走

Collison 原推 7 条，V1 基本是按原文顺序讲下来的：公司是最早的超级智能 → 价格歧视和交叉补贴失灵 → 产品质量的「结构性补贴」 → 质量信息更值钱（智能的互补品） → 赢家通吃还是更分散 → 需求路由（流量分发）生意 → 前提是个人 agent 站在消费者这边。视频开头也照实说了「一共写了 7 条」。

### 1.2 他加了什么（按转写行数粗估，是我的估算，不是精确统计）

全片约 245 行转写：

- **约 50%：转述加翻译原文。**原文的术语都翻成了人话，而且用的是原文里本来就有的现成概念，没有自己造词：有限理性（原文点了 Herbert Simon）、结构性补贴、互补品、需求路由。每个概念他都配了一个日常例子。比如讲互补品，他用「汽车变便宜了，那汽油，道路，其实就会更值钱了」。
- **约 38%：自己补的料和判断**（原文里没有）：
  - 国内日常例子：KFC、麦当劳的优惠券（原文只说了一句 coupons）、订机票最后一步弹出来的保险（原文只说 insurance upsells，他把画面补全了）。
  - 已经在发生的真实产品：Pine（替你打客服电话砍价）、Rowat（试用期快到时提醒你退订），原文都没有。
  - 反例：床垫要睡一阵子才知道好坏，理财顾问可能到最后都判断不了，用来说明 agent 未必看得出真实质量。原文没有这段。
  - 外部研究：微软研究院的模拟市场，模型严重偏爱收到的第一个报价。核过了，确有其事：Magentic Marketplace（arXiv 2510.25779），原文是「first-proposal bias」，速度相对质量有「10-30x」的优势。**但他补了一个原因**，说是「工程师给他们设置的条件」，论文里没有这个说法，这个原因是错的。
  - 时事接口：Meta Muse 上线就被亚马逊屏蔽；国内 AI 助手背后连着淘宝、抖音这类平台。
  - 自己的判断，都挂了「我觉得」：「大概率可能不站在person这边」；「最讽刺的就是，估计只有这个名字本身是personal」。
- **约 12%：开头的框架和结尾。**

### 1.3 他踩的坑（我们别学）

- **把自己的推论挂在原作者名下。**原文结尾只说了一句「Maybe this is too optimistic」。视频里却是「但是作者也说……太乐观了，为什么说太乐观了呢？」，后面接的军备竞赛、面向 agent 的 SEO、渠道权力转移，原推里都没有。这些可能是他自己的，也可能来自别处，比如 Linas Beliūnas 10-16 的付费文章，正文我读不到，没法确认。不管来自哪儿，都不该算成 Collison 说的。
- **补料时加了原文没有的原因**（上面微软研究那条）。
- **开头那句「卡帕奇……世界上现在只有5000个人在真正的很懂行的使用AI」我没核**，出处不明。
- **V2 的结尾金句**「大模型的能力不会消除无知，但会抬高无知的这种代价」是对仗句，正好是创始人说过的 AI 腔，别学。

## 2. 文案结构拆解（V1 为主，V2–V4 用来验证是不是稳定写法）

### 2.1 开头：第一句就是「权威 + 最近干了什么 + 主题」

| 视频 | 第一句 |
|---|---|
| V1 | 「Stripe的CEO前几天发了一条长推，系统性的研究了Agent接下来几年会怎么样重塑商业生态」 |
| V2 | 「华尔街最顶级的量化交易公司JaneStreet，最近分享了一个我也一直被卡住的问题」 |
| V4 | 「梁文锋最近聊到下一代模型，说了两件事情」 |
| V3（变体） | 「今天来跟大家聊一家审美非常好，非常反主流的AI创业公司」，紧接一串运营数字：14 人、零营销费用、估值 100 亿美元 |

4 条里有 3 条是同一个句式，另 1 条换成了数字钩子。说明这是稳定写法，不是个例。

标题也是同一个公式：权威名 + 数量 + 主题。比如「Jane Street 谈投研数据的3个大坑」「Agent重塑下一代商业4大变化」。

第二到第三句给观众一个理由：为什么这个值得听。V1 用的是「这个时代的变化实在太大了……普通人真的很难把握他的方向」，接着「所以认真学习这些行业专家的认知，我觉得是非常有必要的」。

### 2.2 信源权威怎么塑造：专门留 20–30 秒，讲「他为什么懂这件事」

- V1：「Stripe是哪家公司呢？很多朋友可能不太清楚」，然后是「全球大量互联网公司收钱用的那根管道」，再推到 CEO「可能是世界上最能看清楚说互联网上的钱到底是怎么流动的……这样的人之一」。
- V2：「断档第一」「甚至有自己搭建……AI数据中心」「交易量就占了美国股市的很大的一部分」。
- V4：Trajectory 几个连续创业者「分别来自于苹果，Windsurf和Deepmind」。

**关键在于，权威是和主题绑在一起的。**他不报头衔、不报市值，讲的是这个信源站在什么位置，所以看得到这个问题。V1 的链条是：讲的是 agent 怎么改商业，Stripe 是收钱的管道，所以它最清楚钱从谁流向谁。创始人记得的「比任何人都懂」，原话其实留了余地：「可能」「之一」。这层余地本身也减了爹味。

### 2.3 顺带塑造自己：不说「我是谁」，用动作带出来

| 手法 | 原句 |
|---|---|
| 下了功夫 | 「我看了好几遍，觉得非常有收获」 |
| 说清自己的角色：翻译 | 「写得非常的密，堆了很多的经济术语。所以我在这里帮大家去翻译成大白话」 |
| 不藏原文，反而显得自信 | 「有实力的同学我觉得还建议去直接看原文」，结尾又说一遍：「原推不长，我觉得很建议大家去完整的读一遍」 |
| 和观众站一边的同行者 | V2「我也一直被卡住的问题」 |
| 品味 | V3「是我最近看到的很多AI创业公司里面唯一让我眼前一亮的」「大家知道我是Pi Agent的粉丝」 |
| 系列记忆 | V1「我们上期聊到Meta Muse」 |
| 落到观众的业务 | V4「对在创业做项目或者是在企业里想要去落地AI的这些朋友们……肯定也会有很多的收获」 |

整套形象就是：我替你读了一手的好东西，读了好几遍，翻成了人话，原文也给你，你有能力就自己去看。这个人设靠的是「替观众干活」，不靠「我比你懂」。

### 2.4 怎么避免爹味

1. **不确定性交给权威，自己也认不知道。**V1 收尾：「就算是stripe的CEO，这么行业前沿的人……还是很难预测」；V3：「说实话，我其实也不知道哪种更好」。连专家都说不准，他就不用站在高处给答案。
2. **判断都挂「我觉得」，说的是世界，不是观众。**比如「personal agent我觉得最讽刺的就是……」，是在评论这件事，不是在要求观众做什么。
3. **用问题带观众往下推，不下指令。**V1：「大家觉得最后受益的会是谁呢？是使用agent的普通用户吗？其实答案非常不确定」。
4. **建议都是邀请。**「很建议大家去完整的读一遍」「我真的非常建议大家去了解一下」。他推荐的是去看原文、去了解，从不规定观众该怎么做事。
5. **主动替原文讲公道。**V1：「那作者也很客观，就是这些钱不完全是浪费的」，说明广告费本身也是一种信号。

### 2.5 结尾：回到原文，把这篇降级成「一种思路」，再引去看原文

V1 的结尾顺序：「现在这一切都还很早期」 → 「这篇文章更多的是给我们一个思路……思考的方式」 → 「很建议大家去完整的读一遍他的原推」 → 署名。

V2 和 V4 的结尾多一句自己的判断。V4 是「谁的AI在自己的场景里面……更多经验，谁就会取得优势。先跑起来的产品，壁垒会越滚越厚」。

## 3. 和我们 10-19 三条稿的差距

对比对象：安克 Launch（`…eyp926/01-script/manuscripts/current.md`）、2026 主流 agent 锐评（`…4j24wt`）、黑客松遛狗（`…pf76cc`）。规则依据：creator-profile 现行 active 规则，以及 playbooks 现行版本（信息差 v3、反常识 v2、干货 v2）。

先说结论：这三条都不是信源解读稿（安克是走访，锐评是排名，黑客松是故事）。所以差距主要不在「写得差」，而在两处：**我们没有这个体裁**；另外几条写法习惯跨稿反复出现。

### 差距 1：手册里没有「信源精读」这一类

- 信息差 v3 的入选条件要求「创始人和这件事有切身关系……没有切身关系的纯资讯别选」。V1 没有任何切身关系，照样成立，因为信源本身的分量顶上了切身关系。
- 反常识 v2 要求证据推翻观众正在做的动作。V1 不是反常识，是「一位最该懂的人的系统思考」。
- 现行规则「出处只当证据不当主角」（id d097387f）**和这个体裁正好相反**：V1 的主角就是 Collison 那条推文，价值来自翻译、本地化例子，再加我们的立场。

### 差距 2：我们引用外部来源时，不讲它为什么可信，甚至不报名字

- 锐评稿：「香港有位业内人士说得很直白」「钛媒体有位作者拿它……」「有测评说它上线一个月……我没法核实」。
- 安克稿：「微软和领英 2024 年的一份调查里」，没有一句话说明为什么该信它。
- 做得好的地方：安克稿给安克立了分量，「六千多人，每天有四五千人在用」「今年刚进中国民营企业 500 强」，和 V1 讲 Stripe 是同一招。但这是对**被讲的公司**，不是对**引用的信源**。

### 差距 3：自我塑造靠身份声明，不靠动作

- 安克稿：「我们是做 FDE 的，就是驻到企业里、帮企业把 AI 真正落下去的那拨人」，单独一句身份介绍。
- 反例，我们自己写得好的地方：锐评稿「我自己从龙虾换到了 Pi，每天拿它干活」，黑客松稿「我今年自己办过黑客松，也当了很多次评委」。这就是 V1「看了好几遍」那种动作式写法，可以作为我们自己的样板。
- 我们从来不给观众原文入口，没有一句「原文在这，建议你自己看」。

### 差距 4：结尾跨稿套同一个「先别急着 X，先问 Y」指令，这是爹味的主要来源

- 安克稿结尾：「先别急着给每个人配一个 agent。先问两件事」。
- 锐评稿结尾：「先别急着充会员，问自己一句」，前面还有「就别给它交会员费了」。
- 安克稿中段：「要是你公司的 AI 工具还得开三场培训才教得会，先该改的是工具」「这件事得尽快……你只能干着急」，这是警告加规定动作。
- 对照：V1 结尾是「这一切都还很早期」加「去读原推」，没有一句要求观众做什么。
- 两条稿用同一个结尾句式，本身也碰了现行规则「同系列不撞车……不套固定结尾」（id 600e31d6）。

### 差距 5：判断说得太满，不承认不确定

V1 把专家的不确定原样讲给观众，判断都挂「我觉得」「大概率」。我们的判断往往说成定论。比如安克稿的「一般企业最该先抄的就是它」，锐评稿给每个产品下的「夯」「拉完了」。锐评这个体裁本来就要下定论，这条可以留着；但解读类稿应该学 V1。

### 差距 6：讲道理靠自造比喻，他靠有出处的现成概念加日常例子

- 创始人批过「第二把尺子」这类自造比喻。V1 解释机制全用现成概念：有限理性、互补品、结构性补贴、需求路由。先说出是谁提的或原文怎么叫，再配一个人人见过的东西（优惠券、机票保险、汽车和汽油）。
- 安克稿开头的「活动海报四个版本」是**我们推出来的假设场景**，而且贯穿全稿，没有标成「打个比方」。按「真实大于一切」规则（id 4d3d8705），编的示意场景要在稿里标明。V1 的例子都是真东西：KFC、Pine、Rowat、Muse 被屏蔽。

### 差距 7：转述和判断的比例，我们反而偏判断

V1 大约一半是忠实转述。我们的规则「把稿里所有『某某说』划掉，剩下的还要立得住」，在信源解读里会逼着把转述压到最少，判断撑满。V1 说明的是另一件事：转述本身就是价值，前提是信源够硬，加上翻译得好、本地化得好。真正该守的线是第 1.3 节那条：原作者的话和我们的推论分开说。

### 我们比他强的地方（别丢）

- 有 `verify_quote` 核引文、有证据台账。他错挂原作者、给研究补错原因，在我们的流程里本来应该被拦下来。
- 黑客松稿有一手现场（David 9 岁、小区阿姨那句话、改了六十多次 bug），这是他的解读稿给不了的。

## 4. 可以写进手册的改法（措辞草案，待创始人批）

### 草案 A：新增体裁「信源精读」（新建 playbook，不改现有四本）

> # 信源精读
>
> 一位最该懂这件事的人或机构，刚发了一篇有分量的东西（推文、访谈、内部分享、报告），国内还没人讲清楚。我们替观众把它读透：讲清楚它为什么值得信，把原文翻成人话，再配上国内看得见的例子，最后说我们自己怎么看。观众带走的是一个靠谱的信息源，以及读懂它的方法。
>
> ## 什么时候选它
>
> - 信源和题目是绑在一起的：它站的位置让它看得到别人看不到的东西（例如 Stripe 是收钱的管道，所以最清楚钱怎么流动）。只有名气、和题目不搭的，不选。
> - 原文拿得到、核得了。只看过二手转述的，不选。
> - 我们能补上原文没有的东西：国内的例子、已经在发生的真实产品、一个反例或一份研究。
>
> ## 骨架
>
> - **开头**：第一句是「谁 + 最近做了什么 + 讲的是什么」。接着用一两句话说这件事和观众有什么关系，然后说我们读了几遍、为什么要把它翻成人话。
> - **信源为什么可信**：单独一小段，只讲它站在哪个位置、为什么懂这件事，不堆头衔。可以留余地，比如「可能是最……的人之一」。
> - **中段**：按原文的顺序走，原文用的概念照原文的叫法说，说清是谁提的，再配一个观众见过的东西。每讲一条，补一样原文没有的（国内例子、真实产品、反例）。原作者的话用「他说」，我们加的用「我觉得」，不把我们的推论挂到他名下。原文里替反方讲公道的地方要保留。
> - **收尾**：原作者承认的不确定照实讲；我们的判断只说一句；最后告诉观众原文在哪，建议有能力的自己去读。不给观众布置动作。
>
> ## 红线
>
> - 原作者没说的话，不写成他说的。补进来的研究和数字，照原文的结论说，不替它补原因。
> - 引用的原文控制在短句，主体用我们自己的话转述。

### 草案 B：通用规则「引用要说清凭什么信」（加进写作档案 voice_core）

> 引用外部来源时，说出名字，再用半句话讲它为什么懂这件事（它在什么位置、经手过什么）。不写「有位作者」「有测评说」「有业内人士」这类无名来源；查不到名字、核不了的，就不用。

### 草案 C：通用规则「身份靠动作带出来」（加进写作档案 voice_core）

> 创始人的身份，用跟这条题目有关的动作带出来，比如「我天天拿它干活」「我今年办过黑客松」「这篇我看了好几遍」，不单独写一句「我们是做 X 的」。手上有原文的稿子，告诉观众原文在哪，建议有能力的自己去读。

### 草案 D：通用规则「结尾不给观众布置作业」（加进写作档案，和「同系列不撞车」并列）

> 结尾不用「先别急着 X，先问 Y」「就别 X 了」这类给观众下指令的句式。判断说成我们对这件事的看法，可以挂「我觉得」「大概率」；专家自己也说不准的，照实讲。要给建议，就说成邀请（「建议你去看看原文」），不说成规定。

### 草案 E：通用规则「讲机制用现成概念，不自造比喻」（可并入现有「说人话」规则 id 7a0c3485）

> 要讲一个机制时，先找有出处的现成概念（比如有限理性、互补品），说出是谁提的或原文怎么叫，再配一个观众见过的东西（优惠券、机票保险、汽车和汽油）。不自己造比喻来当评判标准（比如「第二把尺子」）。我们自己推出来的场景，要在稿里说明是假设。
