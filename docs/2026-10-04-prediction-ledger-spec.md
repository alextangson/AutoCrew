# 预测账本页面 + 数字对账自动化 — 规格草案（待创始人确认）

2026-10-04。现状：盲预测 / 复盘只有后台接口（`autocrew_insights` 的 `calib_*`），工作台看不到；复盘要在对话里手动触发。创始人要两样都做。

## 一、预测账本（数据页里新增一块，只读）

**汇总条**：评分表版本、已对账样本数、可信度等级（🔴→🔵，同 `calib_status`）、命中率（实际档位 = 预测档位的比例，按平台）、连续同向偏差提醒、待复盘条数。

**列表**（每条预测一行，新的在上）：
- 稿件标题、平台、预测时间、押的档位 + 五档概率、中枢估计、可信度、盲评与自评分歧维度数；
- 状态：待复盘（显示到期日）/ 已对账 / 已解读 / 事后补记（不进校准）/ 完整性警告；
- 已对账的显示：实际播放、落在哪一档、相对中枢偏差 %、是否命中；
- 点开看完整预测（推理因素、反事实、关键假设）和复盘记录。

**空状态**：一条预测都没有时，说明「下一条视频出发布包时会做第一次盲预测」。

**不做**：页面上不能新建、修改或删除预测（预测不可改是规则本身）；不展示盲评通道看不到的东西以外的额外数据。

## 二、数字对账自动化

每天 9:00 回流跑完后，自动给到期的预测做「数字对账」：
1. 到期条件：发布满 3 天（T+3）且该稿件在本平台有回流数据；D+7 再追加一次读数。
2. 自动写入（只追加，不碰预测本体）：实际指标、落在哪一档、相对中枢偏差、是否命中、数据日期。
3. 样本计数：数字对账完成即算一个校准样本（只读实绩，不需要解读）。
4. 「哪些判断被验证 / 推翻、新观察」这部分留空，标「待解读」；之后在对话里由 AI 和创始人补（追加一条解读记录）。账本里「已对账」和「已解读」分开显示。
5. 连续 3 次同向偏差 / 单次 10 倍偏差 / 每 10 条新样本，照现有规则产生提醒（晨报 + 账本汇总条）。

## 边界情况（即验收清单）

- 到期但没有回流数据：不对账、保持待复盘，账本显示「等数据」；不编、不当 0。
- 回流数据被标「待复核」的指标：剔除后再算；剔完没有可用指标 = 等数据。
- 自动对账永远不做「提前复盘」：没满 3 天不碰。
- 事后补记、完整性警告的预测：自动对账跳过，不进样本。
- 已经手动复盘过的：自动对账不重复写。
- 写入要持有资料库写入锁（服务内执行）；丢锁时不写，状态在账本可见。
- 同一视频多平台：每个平台的预测各自对账。
- 自动对账出错（例如日志完整性校验失败）：不写，账本和晨报显示原因。
