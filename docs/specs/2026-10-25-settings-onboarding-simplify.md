## 1. 设置页：三层

1. **常用**（默认打开，一屏看完）
   - 运营平台（现有新页，不动）
   - **写稿的 AI**：一张卡说清现在谁在写（本机 Claude / Codex 已接上，或用自己的模型钥匙），一个按钮「换一个 / 加一条线路」→ 弹窗
   - **平台后台登录**：每个勾了的平台一行，回流正常 / 要登录（ego lite 里打开）
2. **按平台出现**：只在勾了对应平台时显示——公众号（AppID / Secret / 署名）、英文版（ElevenLabs Key + Voice ID）
3. **高级**（折叠，一行入口「高级设置」，单独一页）：端点表、岗位分配、备用线路、搜索 Key、雷达订阅、Telegram、生图通道、发布前把关 Key、语音转写、剪映导出目录、资料库位置、工作区、更新、配置文件

「更多页面」入口（收件箱、品牌校准、写作手册、日志、素材库）从设置里拿走，放进导航的「⋯」菜单。

## 2. 加模型线路：弹窗

一个弹窗「加一条模型线路」，三个选项按推荐顺序：

1. **TokenCamel**（一个钥匙接很多模型）：填钥匙 → 自动测试 → 自动配好写稿 / 调研 / 聊天三个岗位；没有钥匙的给注册和充值入口
2. **DeepSeek**：填钥匙 → 测试 → 配好
3. **其他（我有自己的中转）**：地址、钥匙、协议、模型名，测试按钮

测试失败的原因用大白话写清（钥匙不对 / 余额不足 / 地址连不上）。保存前必须测通，测不通可以「先存着」但卡片上标红。

## 3. 新手引导：三步 + 落地

1. **你是谁、发哪些平台**：现在第 4 步的四个问题 + 平台勾选，放到第一步（先让人说自己，最容易答）
2. **让 AI 动起来**：
   - 检测到本机 Claude Code / Codex：一个大按钮「接上 Claude Code」，下面一行小字说明还需要一个模型钥匙给调研和雷达用（可以先跳过）
   - 没有本机 AI：直接出 §2 的弹窗内容（TokenCamel 推荐在第一位）
3. **资料放哪**：默认放 `~/AutoCrew资料库`，不问；只有检测到旧资料时才问搬不搬
- **落地**：进首页，首页顶部一张「写第一条稿」卡：输入一句灵感 → 点开始写（走现有开写流程），不再让人切到别的 App 自己想说什么

## 4. 边界

- 已有用户不重走引导；设置页搬家后旧配置原样保留，只是换位置
- 弹窗里测试中关窗 / 重复点保存 / 网络断：都有明确状态
- TokenCamel 自助注册没开放时，弹窗里它那一项写「即将开放」或不显示（看 Q1）
- 没本机 AI、也跳过了钥匙：首页顶部固定提醒「还没接 AI，写不了稿」，一个按钮回到弹窗
