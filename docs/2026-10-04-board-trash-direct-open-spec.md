# 看板：稿件卡移入回收站 + 点卡直接进稿件页（2026-10-04，创始人已认）

## 1. 稿件卡「⋯」加「移入回收站」

- 只给 选题 / 写稿中 / 待录制 三列的稿件卡；剪辑中 / 待发布 / 已发布 不给。
- 先弹确认框；确认后走 `content:delete`（软删除），回收站（选题列头「回收站」）里能「恢复」（`content:restore`）。
- 正在写的稿拒绝：`drafting` 且（标题带［生成中］/［调研中］占位前缀，或有还活着的写手认领），
  提示「这篇正在写，先停掉再弃用」，不删。判定由服务端看板数据给（`writing`），点下去前重读一次看板再判，不用旧数据。
- 历史作品记录本来就不上看板生产列，保持不变。

## 2. 去掉卡片侧面板，点卡直接进稿件页

- 点卡标题、`#/board?card=` 深链、本体下前向拖（原 `panel` 动作）都直接打开稿件页 / 工作台。
- 面板里的动作不丢：面板内容整块搬进稿件页（视频稿、本体启用时），作为可折叠的「这条视频的进度」区，
  原「下一步」、原片挂载与核对、候选、分镜、发布纠正、重开文稿、「我现在就要审」都在那里。
- 稿件页标题下那行「回看板看这张卡」改为展开这块区域（不再跳回看板形成循环）。

## 边界

- 三个后段列不出现该菜单项；确认框取消 = 什么都不做。
- 正在写 → 拒绝并提示，不删。
- 删除失败原样提示服务端错误；成功提示可恢复，并刷新看板。
- 菜单打开期间看板暂停轮询（沿用 BackMenu 行为）。
