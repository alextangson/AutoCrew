# 「等你拍板」看得懂 + 写稿交给谁（2026-10-15）

创始人内测反馈：等你拍板 11 件不知道拍什么；只接了 Codex 的人写稿卡住；顶栏只有「复制给 WorkBuddy」让人困惑。

已定（创始人 10-15 选）：写稿 = 默认一个 AI + 可临时换；拍板 = 按稿分组、同手册提案合并、每行写出要判断的问题。

## A 等你拍板

现状：一篇改稿攒出的 5 条手册提案 + 6 条规则提案各占一行；行上只有规则原文，没写要判断什么；「原话」是选卡回的「A」；同一手册几条提案基于同一版本，批一条其余作废但界面不说。

改：
1. **按稿分组**：同一 content_id 的 writing_rule + playbook_change 收成一行「《稿名》改稿攒下 N 条经验，要不要以后都照着写」，点开逐条「要 / 不要」。其他类型（认稿、成片、封面…）不动。
2. **每条写出问题**：规则 →「以后每篇都这样写？」；手册 →「以后《体裁》都这样写？」。和对话里 brief 用同一句（一处定义，两边引用）。
3. **原话补全**：founder_words 只是选项代号（单个字母 / 数字 / 「第 N 个」）时，提案生成处一并存下那张卡/那个选项的内容，界面显示「你选了 A：……」。旧提案没存的，显示「（选卡时的回复，原卡没记下）」，不显示孤零零的『A』。
4. **同手册合并**：同一手册、同一 based_on 的多条提案在组里显示成一份改动（逐段可勾），批的时候一次生成一个新版本，避免批一条作废其余。

边界：
- 组内已批/已拒的条目当场消失，组内全处理完整行消失；处理到一半刷新，剩余的还在。
- 合并批的时候手册已被别处改过（stale）：整组提示「手册已经改过，这几条要按新版重提」，不静默丢。
- 规则上限 12 条：组内批到第 13 条时那条按钮变「要，替换第 X 条」，不让批超。
- 双击 / 重复提交：沿用 request_id 去重。
- 对话里（autocrew_review_inbox list）也按同样分组出 brief，编号到组内条目（「1-3 要，其余不要」能对上）。
- 空组、稿件已删：组照显示稿名（取不到就「已删的稿」），条目照常可处理。

## B 写稿交给谁

现状：「开始写」写死打开 Claude 桌面版（claude:// 深链），没装就退回剪贴板并说「去 Claude 粘贴」；卡片只按状态说「AI 在写」，没人接也这么说；「复制给 WorkBuddy」复制的是只读的「看看这篇到哪一步」。

改：
1. **默认写稿 AI**：引导第 1 步「你想让哪个 AI 来写稿」的选择存成默认（已接上且能写的才可选）；设置 → 宿主里可改。只接了一个就是它。
2. **开始写**按默认打开：
   - Claude：现有深链，带开工指令。
   - Codex：打开 `codex://threads/new`（深链不带文字）+ 指令进剪贴板，toast「Codex 已打开，粘贴发送」。
   - WorkBuddy：指令进剪贴板，toast「粘到 WorkBuddy 里发出去」。
   - 打不开（非 macOS / 没装）：退回剪贴板，toast 说清是哪个 AI、为什么没打开。
   旁边小下拉「换一个 AI 写」只对这一次生效。
3. **开工指令通用化**：现在的「这条视频开工：…」靠 Claude 的 video-session 技能触发；改成任何接了 AutoCrew MCP 的 agent 都看得懂的一句（点名 autocrew_draft / 稿件 id / 平台）。Claude 仍能触发技能。
4. **顶栏按钮**：「复制给 WorkBuddy」→「交给 {默认 AI} 写」（写稿阶段）/「交给 {默认 AI} 看」（其他阶段，保留现在只读查看的意思）；下拉里列其他已接上的 AI。
5. **「AI 在写」说真话**：点了开始写、还没有任何 agent 认领/保存过 → 「已交给 Codex，等它接手」；超过 30 分钟仍没人接 → 「Codex 没接上？重新交给 / 换一个」。有人认领后才说「Codex 在写」。

边界：
- 一个 AI 都没接、也没钥匙：「开始写」不灰，点了弹说明「先接一个 AI」+ 去设置；不假装开工。
- 默认的 AI 后来断开 / 卸载：开始写时检测，提示「默认的 Codex 连不上了」并给换一个。
- 剪贴板写失败：照实说，给出指令原文让人手动复制。
- 重复点开始写：同一选题已有稿件就打开那条（现有 existingDraft），不重复建。
- 被别的会话认领中（claim_held）：照实显示谁在写，不给「重新交给」。
- 只接了 Codex 的引导完成页：去掉「写稿要接 Claude Code 或 WorkBuddy」这句（和 PickStep「Codex 写稿都能做」矛盾）。
