# 数据复盘进入写稿 · 设计卡

目标：把已复核的表现转成有范围、有期限的单一写作实验，供新一轮领包读取。成功证据是同一个实验 ID、来源、建议同时进入写手输入和持久化 writingContract；这不代表模型已采纳或指标已改善。

这是已有写稿工作流的只读装配步骤，不新增 Agent、模型调用、后台采集或发布工具。输入是工作区 `editorial-experiments.json`；观察和建议均为低于本次创作要求的候选，不是事实材料或长期人设。

| 不变量 | 代码落点 | 验证 |
| --- | --- | --- |
| 仅明确 topicId 与平台匹配才注入 | selectEditorialExperiment | 范围与别名测试 |
| 过期、停用、缺文件不注入 | selectEditorialExperiment | 期限及空态测试 |
| 每稿最多一个实验，重叠配置显式报错 | selectEditorialExperiment | 重叠配置测试 |
| 配置坏了不静默装作无建议 | readEditorialExperiments | 无效 JSON/schema 测试 |
| 文本有长度上限，外部定界符不能逃逸 | schema + renderEditorialExperiment | 预算与定界符测试 |
| 观察、建议不能升级为本次指令或脚本事实 | renderEditorialExperiment 中的优先级说明 | 结构测试；真实模型遵循情况尚未评估 |
| 写手与审稿/改稿拿同一份建议快照 | buildWritingContext + contentAttributionOf | 隔离领包与存储测试 |

预算：至多 30 条配置，每条至多 20 个具体选题；每稿 1 条、额外上下文至多 1800 字符；不改研究槽预算或质量门。只读一次本地配置，无网络重试、模型费用或外部副作用。无 topicId 的旧入口维持原行为。

失败显示：不合法配置报告文件名与字段，重叠报告冲突实验 ID。未匹配正常为空；已注入的建议随任务书保存，后续改稿保留当时快照。到期只影响新领包，不改已有稿。

验收：运行隔离临时目录的选择、配置与领包测试，以及相关写作回归、类型检查和 lint。测试不读生产配置、不调用真实模型。模型质量与指标改善未评估，需后续真实稿件和同龄快照判断；本次不做胜负裁决。

操作：配置置 inactive 可停用；新增选题必须显式登记 topicId，不能靠关键词扩散。现有服务在自然重启后加载代码，不中断活跃写作。永久画像、旧稿、发布排期、定时采集不在本次范围内。
