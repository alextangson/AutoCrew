# 人物故事

讲一个人或一类人卡在哪里，后来是什么让她不再卡住。观众带走的不是方法，而是一个记得很久的画面，和一点被触动。

## 什么时候选它

- 有一个真实的人或群体，还有创始人亲历的解决过程。场景、对话、反应都要来自真实素材。
- 卡点是一个看得见的具体动作，比如低头看手机、回头找人，而不是一种抽象的不便。
- 动笔前先拿到素材清单和创始人的口述，要求同「实验演示」。缺了就先问，不动笔。

## 骨架

- **开头**：核心矛盾放在第一句，也就是观众最想知道答案的那个反常。比如「她做咖啡很熟练，可顾客说什么她听不见」。也可以用真实的高光镜头冷开场，先给结局的一角。
- **中段**：用观众的直觉开第一关，「戴个字幕眼镜不就解决了？」，然后每一关都是一个真碰到的坑（「那价格怎么告诉顾客？」），一关一关往下带。技术只当桥，一两句带过。当事人用「她」来指，让她自己的话和动作撑起内容。
- **收尾**：画面落在人身上。回到开头那个画面，做一个前后对照。升华最多一句，没有也行。篇幅跟着内容走。

## 本体裁范文

- `bench-lengkuxiaogu-zhuanye-jiegou`（冷酷小咕，结构卡）：真人怎么出场，怎么让真人自己的话撑起内容。
- `bench-toctou`（创野小朱，归在干货体裁）：闯关结构。
- 本体裁还缺完整范文，等创始人给 2–3 条。

## 红线

- 当事人的话以她本人的表达为准，不替她揣测心情，只写看得见的动作。
- 写残障等身份时，障碍落在环境一侧，不写成她的缺陷。她的医疗和私人信息，没经她本人同意不写。
- 补拍重现的镜头要标「补拍重现」。还没发生的结果，不写成已经发生。
