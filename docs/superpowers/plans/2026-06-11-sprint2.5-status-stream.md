# S2.5：Agent 实时工作状态流 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 chat:turn 的黑盒等待变成看得见的团队接力——loop 每次工具调用实时推送到界面，状态气泡按角色署名展示「侦察员正在扫热榜… ✓ → 编剧正在写稿…」。

**Architecture:** 三层接力：(1) `runLoop` 加可选 `onEvent` 回调（tool_start/tool_end，回调异常不破坏 loop）；(2) `runChatTurn` 把工具名经 `CREW_TOOL_STATUS` 映射成角色+人话标签后转发给调用方；(3) IPC 层加**首条主进程推送通道**——`IpcHandler` 扩展可选 `ctx` 第二参，main.ts 把 `event.sender.send(CHAT_PROGRESS_EVENT, e)` 注入为 `ctx.onProgress`，preload 白名单暴露 `window.autocrew.onChatProgress(cb)`，chat.js 把 thinking 气泡升级为多步状态时间线（完成步 ✓ 累积、当前步带角色徽）。

**Tech Stack:** 零新依赖。安全姿态不变：推送事件由主进程从工具名常量生成（非用户内容）；preload 只监听固定事件名；渲染走 h() 文本节点。

**基线事实（已核对 main@bd9f2fb）：**
- `src/engine/loop.ts`：`LoopOptions {model, systemPrompt, userMessage, history?, tools?, maxTurns?, maxTotalTokens?, fetchImpl?}`；`executeToolCalls(toolCalls, toolMap, messages)` 私有函数循环执行工具。
- `src/desktop/chat-router.ts`：11 个工具（find_topics/generate_script/adapt_platform/flywheel_report/list_drafts/get_draft/read_url/absorb_style/add_style_rule/publish_clipboard/confirm_published）；`runChatTurn(params{message, history?, dataDir?, deps?, fetchImpl?})`。
- `src/desktop/ipc.ts`：`IpcHandler = (payload) => Promise<Record<string,unknown>>`；`chatTurnHandler` 末尾 `try { return await runChatTurn({...}) } catch {...}`。
- `desktop/main.ts:44-52`：统一 handler 循环（sanitizePayload + import_csv 白名单 + `handlers[ch](clean)`）。

```ts
    count++;

      if (!onEvent) return;
      try {
        onEvent({ type, tool: tc.function.name });
      } catch {
        /* 观测层异常不破坏执行层 */

      result = tool ? await tool.execute(args) : `Error: Unknown tool: ${tc.function.name}`;
    } catch (err) {
      result = `Error: ${(err as Error).message}`;
    }
    emit("tool_end");
    messages.push({ role: "tool", tool_call_id: tc.id, name: tc.function.name, content: result });
  }
```

```ts
import { contextBridge, ipcRenderer } from "electron";
import { IPC_CHANNELS, CHAT_PROGRESS_EVENT, chToMethod } from "../src/desktop/channels.js";

// Imports channels.ts (dependency-free), NOT ipc.ts — the sandboxed preload
// cannot require node builtins, so the engine must stay out of this bundle.
// chToMethod exposes the 18 window.autocrew invoke methods (see channels.ts docs),
// plus onChatProgress — the only push listener (fixed event name whitelist).

const autocrew = Object.fromEntries(

    chToMethod(ch),
    (payload?: Record<string, unknown>) =>
      ipcRenderer.invoke(ch, payload ?? {}),

autocrew.onChatProgress = (cb: (e: Record<string, unknown>) => void) => {
  ipcRenderer.on(CHAT_PROGRESS_EVENT, (_event, data: Record<string, unknown>) => cb(data));
};

contextBridge.exposeInMainWorld("autocrew", autocrew);
```

```js
/** 状态时间线：完成步 ✓ 累积，当前步带角色徽（PRD §7.3 可见工作流） */
function renderProgressBubble() {
  if (!activeThinking) return;
  const bubble = activeThinking.querySelector(".chat-bubble");
  if (!bubble) return;
  bubble.textContent = "";
  const list = h("div", { class: "chat-progress" });
  progressSteps.forEach((step, i) => {
    const row = h("div", { class: step.done ? "progress-step progress-done" : "progress-step progress-active" });
    if (step.role && CREW_BADGE[step.role]) {
      row.appendChild(h("span", { class: "progress-badge byline-badge byline-badge-" + step.role }, CREW_BADGE[step.role]));
    }
    row.appendChild(h("span", {}, step.label + (step.done ? " ✓" : "…")));
    list.appendChild(row);
  });
  if (progressSteps.length === 0) {
    list.appendChild(h("div", { class: "progress-step progress-active" }, "正在干活…（写稿约需 30-60 秒）"));
  }
  bubble.appendChild(list);
}

function handleChatProgress(e) {
  if (!activeThinking || !e || typeof e.label !== "string") return;
  if (e.phase === "start") {
    progressSteps.push({ role: e.role, label: e.label, done: false });
  } else if (e.phase === "end") {
    const open = [...progressSteps].reverse().find((s) => !s.done && s.label === e.label);
    if (open) open.done = true;
  }
  renderProgressBubble();
}

if (window.autocrew && typeof window.autocrew.onChatProgress === "function") {
  window.autocrew.onChatProgress(handleChatProgress);
}
```

（事件字段 role/label 来自主进程常量映射，非用户内容；渲染仍全文本节点。）

## Self-Review 记录

- **覆盖**：引擎事件（T1）→ 映射（T1）→ 推送通道（T2）→ 渲染（T3），三层各有测试/断言；回调异常隔离在 loop（吞）与 main.ts（try/catch sender.send）两层。
- **已知妥协**：事件只有 tool 粒度（无 token 流——v1.5 已声明）；多窗口场景只推给发起窗口（event.sender，单窗口 app 正确语义）；end 事件按 label 反向匹配最近未完成步（同名工具并发调用时可能错配——v1 工具串行执行，无此场景）。
- **类型一致性**：LoopEvent（loop）→ ChatProgressEvent（chat-router）→ Record 透传（ipc/main/preload）→ renderer 鸭子检查 e.label/e.phase/e.role；CREW_BADGE 键与 CREW_TOOL_STATUS role 值与 style.css 的 byline-badge-{role} 三方一致（scout/writer/review/analyst）。
