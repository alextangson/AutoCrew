> **创始人定向（2026-07-27）**：赛道 = FDE 与 AI 相关内容；创始人可真人出镜拍摄一部分；**纯 AI 生成视频只作补充素材，不是主路**。初版报告按"无真人出镜"约束把「AI 知识可视化叙事」推为 P0——定向后修订：**真人出镜口播 + AI 全自动后期为主线**，克隆音色支撑不出镜的轻量条目，AI 生成镜头降为 B-roll 补充。

## 0. 结论速览

1. **上一版失败有结构性原因，不是执行问题**：无人物、无叙事、模板感强的图文拼接正是抖音 2025-04《恶意营销号治理规范》"低质同质化"打击画像的中心，也是完播率模型天然歧视的形态。放弃是对的，不要复活。
2. **主线形态：真人出镜口播 + AI 全自动后期**（FDE/AI 赛道）。数据支撑：新榜 2026 年 1-4 月抖音 105 条百万赞 AI 相关爆款里"真人+AI"是绝对主流且爆款率最高；知识口播的信任感与个人 IP 正是 FDE 内容的变现基础。**轻量线：屏录/程序化画面 + 克隆音色**（不出镜但声音人设统一）。AI 生成画面只做比喻/氛围/钩子镜头。
3. **管线五层，每层可独立替换，`timeline JSON` 是稳定接口**：
   `文案/实拍 → 分镜（LLM）→ 素材层（A-roll 实拍 / 屏录 / 程序化图形 / AI 镜头补充）→ 音频层（主音轨锚：A-roll 人声或克隆 TTS，字级时间戳）→ 合成层（Remotion 确定性渲染）→ 成片（含 AI 素材则标注）`
4. **AI 补充镜头采购自国内可 RMB 直连的四家**：火山 Seedance（¥0.95/秒@720p）、可灵 3.0（画面内中文文字唯一靠谱）、阿里百炼万相 Flash 档、Vidu（错峰半价）。全球质量第一梯队恰好就是这几家，合规不牺牲画质。Sora 产品线在关停（API 2026-09-24 停服），不接。**FDE 内容更高杠杆的 B-roll 是屏录与程序化图形（代码高亮/终端打字/架构图由 Remotion 直接渲染）：零成本、可版本化、最技术感。**
5. **音频层首选火山豆包声音复刻 2.0**：5 秒克隆创始人音色，音色 150 元/年，一条 60s 配音约 ¥0.2，**一次请求同时返回音频 + 词级时间戳**——动态字幕对齐零额外组件。开源备选 Qwen3-TTS / dots.tts（均 Apache-2.0，Mac MLX 可跑）。
6. **合成层选 Remotion，但 LLM 不写渲染代码**：LLM 产出语义 timeline JSON（动效字段是受控枚举），zod 校验后由人写好的组件库确定性渲染。"coding agent + 确定性渲染引擎"是 2026 年行业主流路线（Remotion 官方 2026-01 发布 Agent Skills）。剪映降级为逃生口（草稿生成仍兼容，自动导出 macOS 不可行）。
7. **成本**：真人条目素材 ≈¥0-30（0-3 个 AI 镜头）、配音 0（本人原声）；克隆配音条目 ¥0.2/条 + 音色年费 150；纯 AI 叙事条目（补充）¥40-100。月更 30 条（真人 20 + 配音 10）≈ **¥200-800**，比纯 AI 生成路线低一个量级。
8. **合规红线只有一条真死线**：2025-09-01 起 AI 生成合成内容强制标注。主动标注不影响流量（2026 年 1-4 月抖音 105 条百万赞 AI 爆款全部主动标注），漏标被补标才降权。克隆自己音色 + 标注 = 合规。**含 AI 镜头或克隆配音的条目必须标注；纯实拍 + 程序化图形 + 本人原声的条目不属于"生成合成内容"，无标注负担**——真人主线还顺带降低了合规面。

## 1. 上一版为什么失败（死因确诊）

旧方案（v0.3.x tag，当前分支已切掉）：HTML 知识卡片模板 → Puppeteer 截图 → 与 B-roll/TTS 进 ffmpeg 合成 + 剪映工程导出。三重死因：

| 死因 | 证据 |
|---|---|
| 形态撞上治理靶心 | 抖音 2025-04-28《恶意营销号治理规范》点名"预设模板、批量炮制画面高度相似的同质化视频"，配健康分阶梯处罚；模板化图文拼接正中画像 |
| 完播率模型歧视 | 无人物、无叙事的静态卡片翻页，完播天然低；近亲形态（息屏文学/白底大字）2025 后查无持续爆款 |
| 工程半成品 | 旧 `FFmpegCompositor` 核心逻辑带 TODO 未完成（所有输入都从 t=0 开始）；自动化链路从未真正闭合 |

结论：**方向性放弃 HTML 截图拼接路线**。旧资产中仍有价值的部分见 §4.3。

## 2. 内容形态：做什么样的视频

### 2.1 六形式盘点（2025-2026 抖音真实表现；优先级已按 2026-07-27 定向修订）

| 优先级 | 形式 | 判断 |
|---|---|---|
| **P0** | 真人出镜口播 + AI 全自动后期 | 流量上限最高、政策最安全（新榜：百万赞爆款里"真人+AI"是绝对主流且爆款率最高）；FDE/AI 赛道靠专业信任感变现，真人 IP 是必需品。真人录制是唯一非自动化环节——用"每周集中拍一批"摊薄 |
| **P1** | 屏录/程序化画面 + 克隆音色（不出镜轻量线） | FDE 内容的天然形态：demo 一个工具、讲一个架构，屏录+代码动效即画面；声音仍是创始人（克隆音色），人设统一；填充真人拍摄间隙、保更新频率 |
| P2 | AI 知识可视化叙事（文案→AI 画面→配音） | 初版 P0，定向后降为补充形态。调研结论保留：官方顺风口（抖音知识创作砥砺计划、小红书明文鼓励 AI 知识科普），@孩子的一棠课 3 个月 0→170 万粉验证过天花板——若未来开不出镜的第二账号，这条线随时可启用 |
| P3 | 数字人口播（克隆形象/音色） | 不禁止但公域起号难（绿幕念稿完播极低）；留作转化承接与"量产分身"，不冲流量 |
| P4 | AI 配音 + 素材混剪（无人物）、纯 AI 短剧 | 前者易滑入低质批量画像；后者与知识/观点文案错配、抽卡成本高。都不做主线 |
| 弃 | 图文动效快剪、AI 玄学 | 前者已验证失败（§1）；后者被清朗行动点名，结构性死路 |

### 2.2 P0/P1 形态拆解（FDE/AI 赛道）

- **A-roll（真人出镜）**：口播主体。拍摄批处理化——每周集中拍一批，一次多条；灯光机位固定模板化，降低单条启动成本。
- **B-roll 优先级（按赛道适配度）**：① 屏幕录制（工具 demo、代码、终端会话）② 程序化图形（Remotion 直接渲染：代码高亮、终端打字效果、架构图、数据图——零成本、可版本化、最技术感）③ AI 生成镜头（比喻/氛围/开场钩子，每条 0-3 个）。
- **动效字幕是完播的杠杆**：逐词高亮/弹跳字幕 + 关键词强调，全程序化（§3.5）。
- 单条结构：3 秒钩子（koubo 包已有 completion5s 权重与 `[画面]+[口播]+[字幕条]` 纪律）→ 主体（口播 + B-roll 切换，10-20 秒一个视觉变化）→ 收尾引导。
- **P1 轻量条目**：文案 → 克隆音色配音 → 屏录/程序化画面全程 → 动效字幕。零拍摄、全自动，用于高频更新与选题试错；跑出数据的选题再升级成真人条目重讲。
- 首发抖音，同步小红书（AI 知识科普是其官方明文鼓励方向；但小红书对"全 AI 托管账号"直接封禁——发布环节必须保留人工确认，正好与 PRD-v4 发布分级一致）。

### 2.3 政策硬约束（做进产品，不是贴在墙上）

- **必须**：发布时勾选 AI 声明（显式标识）；平台自动写隐式元数据标识。发布 runbook 加一条硬检查项。合成语音、数字人都在必标范围。
- **禁止**：裁角标/清洗元数据（= "引导规避标注"，2025-05-19 专项公告点名）；同一文案/画面/音色多账号批量同发（指纹碰撞连坐）；克隆未授权他人声音/形象；提示词引用真人名人/影视 IP（Seedance 好莱坞侵权函是前车之鉴）。
- **变现设计**：抖音对 AI 内容播放分成极低（有 800 万播放 50 元的实例），从一开始就按商单/私域/知识付费设计，不追平台分成。

## 3. 生产管线五层选型

### 3.1 素材层

**素材优先级（FDE/AI 赛道）**：
1. **真人 A-roll**（拍摄）——主线条目的骨架，处理线见 §3.2；
2. **屏幕录制**——工具 demo/代码/终端，FDE 内容的核心 B-roll；桌面端直接引用本地文件（素材库已能索引本地视频）；
3. **程序化图形**——代码高亮、终端打字效果、架构图、数据图，由 Remotion 组件直接渲染：零成本、可版本化、风格绝对一致，是最"技术感"的画面来源；
4. **AI 生成镜头**——比喻/氛围/开场钩子等抽象画面，每条 0-3 个，采购见下表；
5. 生图 → i2v——AI 镜头的默认工艺（先按风格 prompt 库出首帧再动起来，一致性与成本都优于纯文生视频）。

**AI 镜头采购（2026-07 格局）**：Sora 关停中（API 9 月停服）；竞技场第一梯队 = Google（Veo 3.1 / Gemini Omni Flash）+ 中国系（Seedance 2.0/2.5、可灵 3.0、阿里 HappyHorse）。Runway/Luma 边缘化。开源最强（LTX-2.3）与闭源差 120-200 Elo，肉眼可感——**不走开源自建**。

**默认组合（国内直连、RMB、已备案）**：

| 模型 | 用途 | 价格 | 备注 |
|---|---|---|---|
| 火山 Seedance 2.0/2.5 | 叙事主力：图生视频、多模态参考、30 秒长镜头 | ¥0.95/秒@720p，带参考 ¥0.57/秒 | 中文提示词理解第一；画面内长中文会乱码 |
| 可灵 3.0 开放平台 | 带字镜头与 4K 门面 | ¥0.6-1.2/秒 | **画面内中文文字唯一实测过关**的一家 |
| 阿里百炼 万相 2.6/2.7 Flash | 批量便宜镜头、参考生视频角色一致 | 约 ¥0.2-0.4/秒 | 2.5 之后 API-only，开源版停在 2.2 |
| Vidu 开放平台 | 错峰批量、对口型 | 错峰半价，≈¥0.03-0.05/秒级 | 动漫/角色一致强项 |

补充：质量补充经 fal.ai 调 HappyHorse 1.1（$0.18/秒@1080p，2026 黑马）；数字人口播用火山即梦 OmniHuman 1.5（2026 横评口型第一）；海外模型（Veo 3.1）仅在有海外结算时做质感补充。深折扣国内中转只用于测试，不进生产线。首帧生图可走已有 relay `gpt-image-2` 通道或即梦 Seedream。

### 3.2 真人素材处理线（定向后的新增能力）

真人主线带来一条新管线：**把拍摄素材变成可自动化剪辑的结构化数据**。

- **Ingest**：手机/相机素材导入素材库（`library-store` 已能索引本地视频；PRD-v4 已知"2GB 大文件引用不复制"痛点，桌面端本地路径直接引用即可）。
- **ASR + 字级时间戳**：FunASR Paraformer（fa-zh 时间戳模型）Python sidecar——中文字级 `[start_ms,end_ms]` 精度最强（CER 约为 Whisper 系一半），Mac CPU 可跑。**与 inbox spec"对标视频不做 ASR"不冲突**：那是外部对标素材的排除项，这里处理的是自己拍的素材。
- **Transcript-based editing（按文字剪视频，Descript 范式）**：转写全文 → 与口播稿对齐 → LLM 标记口误/重复 take 选优/离题段 → 按时间戳切。FunClip 已验证"ASR 全文→LLM 选段→按时间戳切"范式可行。人审界面上改的是文字，改完映射回 timeline。
- **自动粗剪**：静音段与口癖（"嗯""然后""就是"）检测剪除（auto-editor 思路），jump-cut 保持口播节奏。
- **主音轨锚**：真人条目里 A-roll 人声即主音轨，字幕/B-roll/信息图全部对齐它——旧 timeline 模型的"TTS 单一时间锚"泛化为"主音轨锚"（TTS 或 A-roll 人声），模型结构不变。

### 3.3 音频层（音色克隆 + 时间戳 + 节奏）

**克隆音色的三个角色**（定向后仍是高优先级模块）：① P1 轻量条目的配音主力（不出镜但声音人设统一）；② 真人条目的修补——说错一句不用重拍，克隆音色补一句，**修补句必须切 B-roll 盖画面**（口型对不上）；③ AI 叙事条目（P2 补充线）的配音。

**主路线：火山引擎豆包声音复刻 2.0**
- 5 秒样本克隆（录授权声明留证），音色 150 元/年；合成 6.5 元/万字符 → 一条 60s（约 300 字）≈ ¥0.2。
- **决定性优势：异步长文本接口一次返回音频 + `sentences[].words[]` 词级时间戳**——配音与动态字幕对齐一个请求解决，TypeScript 纯 HTTP 可封装（`openspeech.bytedance.com/api/v3/tts/*`）。
- 指令控语速/情绪；抖音同源技术，中文口播自然度第一梯队。
- 注意：2.0 系时间戳参数是 `audio_params.enable_subtitle`（1.0 系的 `enable_timestamp` 不通用，传错静默忽略）。

**备选**：MiniMax speech-2.8（文本内 `<#x#>` 精确停顿标记最顺手，但只有句级字幕，需 FunASR 补对齐）；ElevenLabs v3（2026-02 GA，字符级时间戳，需外币卡）。

**开源自部署（可控性路线，Mac 可跑）**：Qwen3-TTS-1.7B（2026-01 开源，Apache-2.0，3 秒克隆，mlx-audio 官方支持）；音质天花板 dots.tts-soar（小红书 2026-06 开源，48kHz，Apache-2.0，社区 MLX 移植）；"最像自己"走 GPT-SoVITS v2Pro 用 1 分钟干声微调（MIT，Mac 原生支持）。**避坑**：F5-TTS（CC-BY-NC）、Spark-TTS（改 NC）、MegaTTS3（不能自助克隆）、Fish S2-Pro（商用要买授权）、IndexTTS2（时长控制论文级最强但权重商用需 B 站书面授权，且 duration 接口开源版未启用）。

**时间戳与对齐**：走火山则零额外组件；走开源/MiniMax 则复用 §3.2 的 FunASR sidecar 做强制对齐。工程要点：TTS 前做数字规范化（"2026"→"二零二六"），否则对齐必翻车。

**节奏卡点（业界实际做法，逐级递进）**：
1. 逐句生成 → 拿真实时长 → 在 BGM 节拍网格上摆放，句间静音补齐到下一拍；
2. 拍点用 librosa `beat_track` 起步（有 20-60ms 系统性偏晚，加人工偏移校正），进阶 BeatNet（可出重拍，只卡重拍更自然）；
3. 句子略超槽位用 `ffmpeg atempo` ±5% 无感伸缩，再大就重新生成而不是硬拉；
4. 字幕入场帧绑定词级时间戳，snap 到拍点。

### 3.4 合成渲染层（Remotion + timeline JSON）

**选型：Remotion v4（2026-07 仍日更，46k stars）**。理由：TS 同栈；Apple Silicon 本地渲染（30-90s 竖屏片分钟级）；动效上限 = React/Canvas/WebGL 上不封顶；`@remotion/captions` 原生逐词字幕（`createTikTokStyleCaptions`）；**官方 AI 工具链全行业最成熟**（system prompt / llms.txt / 2026-01 发布 Agent Skills，`npx skills add remotion-dev/skills`）。

**License（要盯的一条）**：个人/≤3 人公司免费含商用。≥4 人后自动化管线按 Automators 计费（$0.01/render，最低 $100/月）。当前阶段免费；**团队到 4 人是触发点**，届时评估付费或切 HyperFrames（HeyGen 2026-04 开源，Apache 2.0 无任何门槛，HTML/CSS 路线真渲染成片、非截图拼帧，生态较浅是唯一短板）。

**核心架构纪律：LLM 不写渲染代码**。
- LLM 产出**语义 timeline JSON**：多轨（视频/字幕/配音/BGM）、clip 带入出点、动效字段是**受控枚举**（`subtitleStyle: "bounce-word"`、`transition: "whip-pan"`、`beatSync: true`）；
- 每个枚举对应一个人写好的 Remotion 组件，zod 校验 → 确定性渲染；LLM 管创意参数，渲染确定性由模板库保证；
- 新动效模板用 Claude Code + Remotion Skills 开发，**进库后才进生产**——动效库随迭代增长，这就是"迭代快"的落点；
- 骨架参考 Shotstack/阿里云 ICE 的 timeline→tracks→clips，动效表达参考 Creatomate 的语义动画名，schema 带版本号（OTIO 式）便于迁移。
- 中文字体：字体文件放 `public/` 走 `@remotion/fonts` 的 `loadFont()`（阻塞渲染防豆腐块），CJK 必须子集化。

**值得抄管线设计的开源项目**（不直接用，它们的渲染层都是 moviepy 档次）：NarratoAI（六阶段中间 JSON + 回填真实时长 + TTS word-boundary 字幕）、MoneyPrinterTurbo（99k stars；素材去重、最终拼接用 ffmpeg concat demuxer 防画质劣化）、FunClip（ASR 全文→LLM 选段范式，处理外部素材时用）、OpusClip Agent Opus（子 agent 分工 + 中间产物逐层校验）。

### 3.5 字幕

正文字幕一律 Remotion 程序化压制（模型内文字不可靠）；画面内装饰性文字（标题卡/招牌）才交给可灵 3.0 或"带字图→图生视频"。字幕时间戳来源：配音条目直接用 TTS 词级时间戳（§3.3，零额外组件）；真人条目用 FunASR 对齐（§3.2）。

### 3.6 剪映：逃生口，不是主干

pyJianYingDraft 生成新草稿在新版剪映仍可用，但读取模板草稿（6+ 加密）与自动批量导出（仅 Windows + 剪映 ≤6）都不行，macOS 无自动导出。定位：**需要人工精修的片子从 timeline JSON 转一份剪映草稿**，人在剪映里改和导出；自动链路不经过剪映。旧仓库的剪映导出器（v0.3.10 `packages/studio/.../jianying/`）可作起点。

## 4. 推荐架构：接进 autocrew

### 4.1 数据流（两种条目共用一条 timeline 主干）

```
Content(approved) ──手动/chat 触发──▶ 视频构建 job（持久化五态 + lease + SSE，照抄 deep-research spec §2）
  │
  ├─ 真人条目（P0）：A-roll 导入 → FunASR 转写对齐 → LLM 粗剪（选段/去口癖/标口误）
  │    → 主音轨 = A-roll 人声；修补句走克隆 TTS（强制盖 B-roll）
  │
  ├─ 配音条目（P1/P2）：口播稿 → 克隆 TTS 逐句合成（词级时间戳随返）→ 主音轨 = TTS
  │
  → 分镜升格：videoKit.storyboard + 主音轨时间戳 → timeline JSON 草案（LLM，受控枚举 + zod）
  → 素材阶段：屏录引用 / 程序化图形参数化 / AI 镜头 首帧生图→i2v
      （并行，asset 状态机 pending→generating→ready→confirmed）
  → 节奏：BGM 选择 + 拍点检测，B-roll 切换点与字幕入场 snap 到拍点
  → 对轨：主音轨为单一时间锚，视频片段截尾/慢放/loop 对齐（容差 0.5s，沿旧设计）
  → 渲染：Remotion 本地渲染 → contents/<id>/assets/final.mp4 + 封面 + 字幕文件
  → 审片：素材面板逐镜头预览/重抽/换 prompt；真人条目在文字稿上改选段（复用 article-images 交互范式）
  → 发布件：videoKit 既有 caption/标题 + AI 标注判定（含 AI 素材/克隆音则硬提示勾选声明）→ 剪贴板发布流程
```

### 4.2 接入点（照仓库既有惯例，六处）

1. **数据**：`Content.videoBuild?: VideoBuild`（与 `videoKit?` 平级）；产物落 `contents/<id>/assets/`（`Asset.type` 已支持 video/audio/subtitle，schema 零改动）；timeline JSON 落 content 目录、版本化。
2. **执行**：持久 job + `claimedAt` lease + 启动回收 + SSE 进度，样板 `src/desktop/inbox-runtime.ts`；所有入口投递即返回，绝不阻塞聊天。
3. **Key**：新建 `<dataDir>/video.json`（火山/可灵/百炼/Vidu 各 key + 音色 ID），走 settings 掩码 + 掩码回传守恒 + 变更热重启三件套（justoneapi 样板）；缺 key = blocked 态 + 人话指引，不静默降级。
4. **IPC**：`video:build` / `video:status` / `video:assets` / `video:settings_get/set` + SSE `video:updated`，三处登记（channels / channel-contracts / ipc）。
5. **chat 工具**：`build_video`，角色标签 `editor`（剪辑师）——呼应 PRD-v4 §4.2 预留编制。
6. **计时**：`Content.videoReadyAt` 新戳，`production-timing.ts` 三段扩四段（纯函数，改动约 10 行）。

**分包纪律（红线）**：remotion/ffmpeg 等重依赖绝不进主 package.json（当前生产依赖仅 4 个）。渲染器独立 workspace（如 `render/`，参照 frontend/ 先例），主进程经子进程/CLI 调用；未安装渲染包 = 可见的 `not_configured` 状态。

**外部 API 封装**：照 `justoneapi.ts` 范本——baseUrl/timeout/fetchImpl 注入、业务码三态映射表导出供测试、错误消息不回显带 token 的 URL。视频生成是分钟级异步任务，封装层要带轮询 + 任务 ID 持久化（进程重启后可续查，不重复扣费）。

### 4.3 旧方案复用/不复用

**复用**：timeline 数据模型思想（单一时间锚——泛化为"主音轨"、visual 挂 `linkedTts[]`、asset 五态机——`git show v0.3.10:src/types/timeline.ts`）；时长对齐策略（截尾/0.7x 慢放/loop、容差 0.5s）；剪映导出器（逃生口）；打标→人工确认的产品形态。
**不复用**：HTML 卡片截图路线（死因见 §1）、半成品 FFmpegCompositor、豆包旧 TTS provider、MiMo 视频拆解线（已被 justoneapi + pattern-store 替代）。

### 4.4 IP 资产层（新概念，账号的护城河）

真人形象与声音就是主 IP。`<dataDir>/video-identity.json` 存账号的视听指纹：克隆音色 ID、字幕/动效风格主题（字体、代码配色、强调色）、程序化图形主题、AI 镜头美术风格 prompt 库（带负面词）、BGM 曲库偏好；若开 P2 不出镜账号，再加虚拟讲述者参考图集。所有生成环节从这里取锚——**换一个账号 = 换一份 identity 文件**，天然支持未来矩阵而不触发同质化判定（画面/音色/文案指纹都不同）。

### 4.5 与数据飞轮闭环

发布后完播率/5s 完播（CSV + 扩展双通道已通）→ retro 归因到 timeline 特征（钩子镜头类型、节奏密度、字幕样式）→ 反馈进分镜 prompt 与动效模板选择。pattern cards（对标拆解）已注入写稿，V2 起同样注入分镜生成。

## 5. 分期路线

**V0 · 走通一条真人条目（walking skeleton）**
一条实拍 A-roll 导入 → FunASR 转写 + 字级时间戳 → 转写稿上人工选段（LLM 粗剪建议）→ timeline JSON → 动效逐词字幕 + 屏录/程序化图形 B-roll（各 1 种模板）→ Remotion 本地渲染成片 → 人工审片 → 剪贴板发布。AI 镜头可选插 1 个验证采购链（Seedance 或万相）。
验收：一条真实成片发上抖音；全链路失败可见（每阶段独立可重试）；转写→选段→成片的映射经得起改稿往返。

**V1 · 自动化与音色**
自动粗剪（静音/口癖检测）；创始人音色克隆（5 秒样本 + 授权声明，火山复刻 2.0）→ P1 轻量条目全自动跑通（文案→配音→屏录/程序化画面→成片）+ 真人条目修补句；动效字幕组件库扩到 3-5 种受控枚举；BGM 拍点检测 + 切换点卡拍；素材面板（逐镜头预览/重抽/换 prompt/上传替换，复用 article-images 范式）；剪映草稿逃生口。
验收：盲测克隆配音"AI 味"可接受；真人条目单条人工干预 <15 分钟（不含拍摄）、P1 条目 <5 分钟；卡点视觉上成立。

**V2 · 学习与规模**
对标学习驱动：pattern cards 注入分镜生成，justoneapi 时长/结构数据参与节奏决策；数据回喂（完播率 → timeline 特征归因：钩子类型/B-roll 密度/字幕样式）；P1 试错→真人重讲的选题升级闭环；IP 资产层多账号支持；可灵带字镜头、数字人口播席（OmniHuman）作转化承接；托管定时（挂 campaign workflow-engine）。

每期迭代点都收敛在三个可替换位：**素材层换源**（实拍/屏录/AI 镜头供应商，timeline JSON 不动）、**音频层换 TTS**（火山→开源自部署）、**合成层加模板**（受控枚举扩充）——这就是"相对灵活的模块"的具体含义。

## 8. 风险与红线

1. **标注红线**：发布必勾 AI 声明；绝不裁角标/洗元数据。发布 runbook 加硬检查项。
2. **同质化连坐**：多账号绝不同素材同音色同发；IP 资产层按账号隔离。
3. **提示词 IP 风险**：分镜 prompt 过滤真人名人/影视 IP 词（Seedance 侵权函前车之鉴）；素材生成日志留存备查。
4. **模型价格/存续波动**：Sora 关停、即梦 2026-04 涨价都发生在半年内——timeline JSON 与素材层解耦就是对冲；video.json 支持多供应商 key 并存。
5. **剪映草稿脆弱**：字节改版即碎，只做逃生口不做依赖。
6. **平台分成幻觉**：AI 内容播放分成极低，变现按商单/私域/知识付费设计。
7. **渲染依赖膨胀**：重依赖锁在独立 workspace，主仓库 4 依赖纪律不破。
8. **修补句露馅**：克隆音色修补的句子与画面口型对不上——纪律：修补句必须切 B-roll 盖画面，渲染层校验强制执行。
9. **真人瓶颈反噬更新频率**：拍摄断档时 P1 轻量条目兜底；但 P1 占比过高会稀释真人 IP——比例进数据回喂观察。

## 9. 明确不做

- 全自动发布（维持 PRD-v4 发布分级：人亲手点发布）
- 剪映自动导出（macOS 不可行）与剪映模板草稿读取（6+ 加密）
- 对标视频下载/ASR 拆解（外部素材的排除项，沿 inbox spec；自己拍摄素材的 ASR 是 §3.2 能力，不在此列）
- 纯 AI 短剧、图文快剪复活、AI 玄学
- 开源视频模型自建 GPU 集群（质量差 120-200 Elo，不值）
- V0 做双 TTS 路线（一套跑通再谈备份）
