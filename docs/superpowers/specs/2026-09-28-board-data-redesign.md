## 第一批：看板 + 发布状态回写

### A. 列与卡片状态
1. 读取中：列头照常显示，卡片区写「读取中」；不显示 0（避免误以为清空了）。
2. 读取失败（服务没起 / 资料库不可用）：整板一行错误说明 + 重试按钮，不渲染空列。
3. 空列：变窄，只留一行说明（例：剪辑中「Codex 在剪的会出现在这」）。全部为空（新装）：选题列给「＋新想法」入口。
4. 某列很多（待录制 11）：列内显示前 8 张，「还有 N 条 ▾」展开；不做列内滚动条。
5. 标题超长：卡片最多 3 行，悬停看全文。
6. 已归档稿件：不进任何列（修掉现在落进「在写」的 bug），回收站入口保留。
7. 轮询刷新（现为 3 秒）：拖动进行中、菜单打开时暂停，结束后再刷；刷新不打断正在看的展开状态。

### B. 选题列与「开始写」
8. 来源标签：radar:* → 「雷达 · 具体源」；灵感收件箱进来的 → 「收件箱」；其余（Claude/Codex 会话里建的、手动建的）→ 「你建的」。代码里没记「哪个会话建的」，不编造。
9. 「开始写」= 建稿件（选题进「写稿中」）+ 打开 Claude 桌面版新会话并预填指令：`claude://code/new?q=<指令>&folder=<AutoCrew 程序目录>`（已核实：只预填、不自动发送，由创始人按发送）。指令用 video-session 技能的触发说法，带选题标题和 topic_id，保持简短（App 对 q 有长度上限）。打不开（未装 Claude / 链接被拒）时退回：指令复制到剪贴板 + 一行提示，不静默。
10. 拖到「写稿中」= 点「开始写」，同一套逻辑。
11. 双击 / 两个标签页同时点：同一选题已有稿件就直接打开那篇，不建第二篇。
12. 选题被删 / 已被别处开写：卡片消失时给一行提示，不报错。
13. 分数缺失（手动建的没评分）：不显示分数框，不写 0。

### C. 拖动与改阶段（防呆）
14. 只允许一种拖动：选题 → 写稿中。其余列之间不能拖（现在是 force 强改，能把没剪的稿拖到已发布）。拖到不允许的列：卡片弹回 + 一行说明「这一步由 Codex 交接 / 发布推进」。
15. 真要手动改阶段（例：退回待录制重录）：卡片「⋯」菜单里做，往回退要二次确认，写明会发生什么（例：交接会被撤回）。
16. 往前跳（例：直接标已发布）只走 D 组的「我发了」，不从菜单跳。

### D. 发布状态回写（已发布列的数据源）
17. 数据源：项目 06-publish/publish-plan.json 的 platforms[].publication（Codex 发布时写的）；看板读它，不再只看稿件状态。
18. 任一平台已提交（定时 / 审核中 / 已公开 / 手动发）即进「已发布」，稿件状态同步为 published。卡片列出这条发了哪些平台、各自状态；没投的平台不标红（创始人可能只想发部分平台）。18b. 同一主题以后再加公众号等其它形态：是该主题下的另一篇稿件，单独一张卡走自己的列；两张卡都标「同主题」互相可跳。
19. 发布时间：定时的取定时时间，已公开的取实际时间；「最近 5 条」按这个时间倒序，未来的定时排最上面。
20. 定时时间已过：写「应已公开」，等数据回流确认后改「已公开」；不假装知道。
21. 平台审核不通过 / 被下架：该平台一行标红写原因，卡片仍在已发布，不自动挪回。
22. 你自己在平台上发的（像今天视频号）：卡片每个平台行有「我发了」，可选填链接；写回稿件，标注「手动」。点错可撤销。
23. publish-plan 缺失 / 格式坏 / 出现不认识的状态：显示「发布记录读不到」或「状态：原值」，不隐藏、不当作未发布。
24. 发布计划里有但账号资料里没勾选的平台：照样显示（以实际投了为准）。
25. 旧的「确认已在平台发布」「标记发布中」「推送公众号」等多个入口：视频稿收敛到卡片「我发了」+「让 Codex 发布」两个；公众号推送保留在文字稿的发布页（本批不动文字稿流程）。

### E. 其它全局
26. 线路异常横幅 → 顶栏：线路正常时什么都不显示；异常时一个红点 +「线路异常」（多条坏写条数），点开看是哪条线路 + 去设置。
27. 导航：看板 / 数据 / 设置。灵感收件箱、品牌校准、任务日志、素材库收进设置页分组；增长（目前空）不露出，路由保留。今日页（Dashboard）撤掉，根路径进看板。
28. 右侧总编辑：看板、数据页默认收起；写稿页展开（沿用已有偏好逻辑）。
29. 预估时长：按上一条已登记成片的「字数 ÷ 时长」算（现在约 315 字/分）；还没有登记过成片时不显示。
30. 封面缩略图：用已选那版的 3:4；没选就不放图。
31. 时间一律本地相对时间（沿用已修的 time-format）。
32. 点卡片：进这条的现有详情页（写稿页 / 剪辑看板 / 发布页）。单条视频页的改版不在本批。

## 第二批：数据页（按月）+ 数据与稿件关联

### F. 数据与稿件关联（现状：35 条平台数据的 contentId 全是空）
33. 自动关联：平台标题与稿件标题 / 发布计划里该平台的标题相近，且发布日期差 ≤1 天 → 自动挂上。
34. 对不上（标题各平台不同，如 09-09 视频号「用 AI 一年」vs 其它平台「别再收藏提示词」）：放进「未关联」分组，每行可手动「关联到…」一条稿件或「和上一行是同一条视频」。
35. AutoCrew 之前做的老视频（没有稿件）：按「同一天 + 标题相近」合成一行，合不了就各占一行；可手动合并 / 拆开。
36. 手动关联要能撤销；自动关联错了手动改后，以后不再自动覆盖。

### G. 数据页显示
37. 月份切换：默认本月；本月还没数据时显示最近有数据的月份，并写明「本月还没有数据」。
38. 平台卡片显示该月播放中位数 + 条数；某平台当月少于 3 条写「样本太少」，不给中位数。没有这个平台的数据：不显示这张卡。
39. 表格一行一条视频，四个平台列；某平台没发写「—」，发了但数据没回来写「未回流」（两者要区分）。
40. 加粗规则：高于该平台全部历史中位数（不是当月），避免当月样本少时乱加粗。
41. 百分比统一保留 1 位小数（现在有 2.1831% 这种）。
42. 数据截至时间 + 来源（CSV / 自动回流）+ 自动回流开没开，一行写在右上；导入和开关挪到设置页。
43. 抓取失败 / 登录过期：这一行变红写原因 + 去设置，不静默。
44. 复盘：列出已有复盘，「生成本月复盘」按钮；生成要调模型，线路坏时按钮旁写明「线路异常，暂时生成不了」，失败要显示错误。
45. 在验证的写法：只显示一句话 + 看哪个指标 + 状态；长说明点开看。
46. 点一行：看这条的详细数据（各次快照）和当时的稿子；本批只做到跳稿件页 + 快照列表。
