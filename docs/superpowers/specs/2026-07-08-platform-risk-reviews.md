# 平台发布风控评审（IA v5 V5.4 · PRD-v4 §6 红线执行件）

> 口径:任何对外写操作,逐平台过本评审;**评审通过 ≠ 默认开启**——每个平台的自动化发布
> 均为 opt-in + 用户对每次提交显式确认(「人最后一击」边界不动)。
> 状态标记:✅ 已通(可实施) / 🟡 评审中(缺创始人裁决) / ⛔ 暂缓。

## 1. 公众号（A 级 · ✅ 已通,已实施)
- 路径:官方草稿箱 API(`draft/add`),非群发;最后一击=创始人在 mp.weixin.qq.com 点「群发」。
- 暴露面:appid/secret 存本地 openclaw config;违禁词门前置。
- 回滚:草稿可删;已群发不可撤(平台规则,与我们无关)。

## 2. X(Twitter)（API 直发 · 🟡 评审中）
- 路径:X API v2 `POST /2/tweets`(官方 API,非模拟人类——合规面最干净)。
- 前提(创始人):开发者账号 + app key;免费档写配额有限(以实施时官方文档为准),Basic 档更稳。
- 风控信号:官方 API 无风控风险(就是给机器用的);内容层面走违禁词门+画像审。
- 最后一击:产品内确认卡(平台无草稿概念)——确认卡展示最终分楼预览,用户点「发」才调 API。
- 回滚:单帖可删;thread 逐帖删。
- 语言/persona:**待创始人裁决**——中文号还是英文号(PRD-v4 §4:每平台席位一个 persona)。

## 3. Reddit（API 直发 · 🟡 评审中）
- 路径:官方 OAuth `POST /api/submit`(script app 类型,个人账号授权)。
- 前提(创始人):Reddit 账号 + script app(client id/secret);账号需有基础 karma(新号发帖易被 spam 过滤)。
- 风控信号:各 subreddit 自治规则(自我推广限制/披露要求)——**pack 已内置披露与反营销腔纪律**;
  发帖频率保守(≤1 帖/日/子版)。
- 最后一击:产品内确认卡,展示目标 subreddit + 标题 + 正文预览。
- 回滚:帖子可删(负分痕迹留存)。

## 4. 今日头条（B 级预填 · 🟡 评审中）
- 路径:无公开自助 API(MP 开放接口需服务商资质)→ B 级=浏览器预填 mp.toutiao.com 编辑器,
  用户过目后点「发布」。近期交付形态:剪贴板(已实现)。
- 风控信号:头条对第三方工具注入的容忍度未知——预填只做「往编辑器填内容」,不碰发布按钮;
  频率=人写作节奏。
- 回滚:文章可删/可撤回修改。

## 5. 抖音 / 视频号 / 小红书（B 级预填 · ⛔ 暂缓至视频链就绪）
- 发布件=标题/文案/tags/封面(+成片,用户自备);预填=创作者后台表单填充,上传视频与提交永远人做。
- 三平台对自动化工具风控敏感(尤指抖音)——预填实现前需逐平台单独补充:注入方式(剪贴板辅助 vs
  DOM 填充)、触发频率、账号分级(新号不做)。
- 近期交付形态:剪贴板(已实现)+发布件生成(V5.4b 视频链)。
