# 认稿弹窗给足信息（2026-09-29，创始人已确认：四项都要，预览重新计时）

## 为什么

`autocrew_video confirm` 弹的 Mac 窗只给几行字（原片文件名、稿名、平台、封面字、时长），创始人在盲点：没法核对原片是不是这条稿、封面字配不配。补交接（剪完才交）时，成片和封面已经存在，弹窗也不提。交接成功后也没有「下一步去哪」。

## 边界（不变的）

弹窗只负责**认稿 + 封面字 + 时长**。成片（gate3）和封面（gate4）的批准只在工作台；弹窗里只提示「在哪」和提供打开入口，**不出现任何批准按钮**。预览动作一律不写记录，只有点「确认」才写确认记录和 decisions。

## 要做的四项

代码在 `src/modules/video/handoff/confirm.ts`、`dialog.ts`（osascript 注入口，测试用假的），交接成功点在 `handoff.ts`。

1. **确认窗多几行**（`summary`）：原片时长（`probeMedia`，拿不到写「时长读不出」）与文件修改时间；认稿依据（回执候选的 `evidence`，L2 带 score 两位小数）；定稿第一句（正文首个句子，截 40 字）。
2. **「改一下」换成「查看 / 修改…」**：点开是 `dialog.choose` 列表：
   - 预览原片 → `open <aroll_path>`（系统默认播放器）
   - 看定稿 → `open` 项目里当前定稿文件（`01-script/manuscripts/current.md`，按绑定解析）
   - 在工作台打开 → `open http://127.0.0.1:<port>/#/editor/<content_id>`（port 取服务实际端口，缺省 4317）
   - 改封面字和时长 → 原来的 `editValues`
   做完回到确认窗（同一套值）。列表取消 = 回确认窗，不算放弃。
3. **补交接时提示已有产物**：绑定项目里已有成片候选（`04-edit/` 下 mp4/mov，取最新一个的文件名+时长）或 `05-cover/` 子目录里的图（数张数），确认窗多一行「已找到成片：… ／ 已找到封面：N 张（去工作台批）」。没有就不显示这行。
4. **交接成功后的提示**：handoff 真正提交（`handed_off`，非重放）后，弹一个**不阻塞**的通知窗：「已交给剪辑：<标题>。成片和封面到了会出现在工作台。」按钮「打开工作台」（点了在 AppleScript 里 `open location` 这条的工作台地址）和「好」。用分离的 osascript 子进程，handoff 回执不等它。弹不出来（无图形会话）只记 warning 进回执，不影响交接结果。

## 计时（创始人定：预览重新计时）

- 每次从「查看 / 修改…」里执行预览/看稿/打开工作台后回到确认窗，**确认窗的 5 分钟重新开始**。
- 总时长硬上限 **20 分钟**（从 confirm 调用开始算）：MCP 调用一直挂着，不能无限续。到上限按 `confirm_timeout` 处理，回执说明「看了太久，重新 confirm」。
- 选择列表窗、输入窗本身仍用剩余时间。

## 失败要看得见

- `open` 失败（文件被挪走/删了、没有默认程序）：回到确认窗时顶部加一行「刚才打不开：<原因>」，不假装打开了。
- 工作台打不开：先探一下端口（`http://127.0.0.1:<port>/` 有响应），不通就在确认窗写「工作台没在运行，打不开」，不去打开空页面。
- 定稿文件不在：同上，写原因。

## 不做

- 弹窗里不放图片、不播视频（系统弹窗做不到，预览交给系统程序）；不加批准；不改 match 算法；不改工作台页面。

## 验收（测试，全部用假 dialog / 假 opener，不弹真窗、不真 open）

- summary 含时长、依据、首句；时长读不出时写明。
- 「查看 / 修改…」四个动作各自：调用了正确的 open 目标；回到确认窗；不写确认记录。
- 预览后确认窗 timeout 重新计满；总时长到 20 分钟上限回 `confirm_timeout`。
- open 失败 / 工作台不通 / 定稿缺失：下一次确认窗文本带原因。
- 补交接：有成片/封面时多那一行，没有时不出现。
- 交接成功触发一次通知（假 runner 记录到调用），重放不触发；通知失败只进 warning，交接仍 ok。
- 现有 confirm / handoff 测试全部照过。
